# 国际化（i18n）与无障碍（a11y）策略

> 商业级前端规范。当前前端（picker/settings）是轻量 vanilla HTML（零构建链），i18n/a11y 已渐进实施。

## 无障碍（a11y）— 已实施

- `<html lang="zh">`：声明语言（picker/settings）
- **键盘导航**：picker 项目列表项 `tabindex=0` + `role=button` + `aria-label` + Enter/Space 选中（不只鼠标）；settings 插件列表内按钮原生键盘可达
- **列表语义**：`ul#plugins role=list` + `li role=listitem`（显式 ARIA）；picker 项目用 role=button（每项独立可激活，button 语义比 listbox 更准确——listbox 适合单选列表，此处是"选择并启动"）
- **动态区域**：`#diag-output` `role=status aria-live=polite aria-atomic=true`，更新时屏幕阅读器播报
- **可读按钮文本**：所有 `<button>` 有中文/英文文本（i18n 切换），非纯图标
- **对比度 WCAG AA + AAA**：全量审计两面板文本/图形色（相对亮度法），结果——
  - 正文 `#1a1a1a`/`#fafafa` ≈ 16:1（AAA）
  - 主色按钮 `#fff`/`#1d4ed8` ≈ 7.6:1（AAA）；hover `#1e3a8a` 更深
  - 链接/次主色文本 `#1d4ed8`/`#fafafa` ≈ 7.2:1（AAA）
  - 次要文本 `#595959`/`#fafafa` ≈ 6.7:1（AA，接近 AAA）
  - 指标/禁用态文本 `#4b5563`/`#fafafa` ≈ 7.8:1（AAA）——原 `#6b7280` 仅 4.35:1 未达 AA，已修正
  - 错误 `#b91c1c` ≈ 7.5:1（AAA）；徽章 `#166534`/`#dcfce7`、`#4338ca`/`#eef2ff` 均 > 7:1（AAA）
  - 收藏星标 `#d97706`（图形对象，WCAG 1.4.11 非文本对比 3:1）≈ 3.06:1 ✓
- **确认对话框**：卸载/敏感权限用 `confirm()`/`alert()`（原生可访问）

## 国际化（i18n）— 已实施（双面板）

picker + settings 均实施渐进 i18n（同机制，零框架）：
- **字典**：`I18N` 对象，zh/en 两语言（picker 6 key、settings 9 key）
- **locale 检测**：`navigator.language`，`en*` → en，否则 zh
- **标记**：`data-i18n="key"` 元素
- **应用**：`applyI18n()` 启动遍历 `[data-i18n]` 填充
- **扩展**：加 key + 翻译即可，无需框架；动态文案（如 aria-label）用 `t(key)` 内联

## 已确认的设计决策

### picker 项目列表用 role=button 而非 role=listbox
- 每个项目独立可激活（点击/Enter → 启动），是"动作"语义，button 更准确
- listbox 适合"单选/多选列表"（有 aria-selected 选中态），此处无选中态
- 两者都满足键盘可达 a11y；选 button 因语义匹配

### 进程隔离插件网络（非 i18n/a11y，但安全相关）
- OS 级网络沙箱无 root 跨平台不可行（unshare 需 CAP_SYS_ADMIN，sandbox-exec 弃用）
- 替代：WASM 插件 host_api 强制域名白名单（强隔离）+ 进程隔离插件安装时 UX 警告（用户知情）
