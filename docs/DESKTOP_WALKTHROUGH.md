# 桌面壳原生面人工走查清单

> 目的：Web 层（Studio）已有三轮真机走查与全量自动化测试覆盖；本清单覆盖**无法自动化驱动**的
> 桌面壳原生面（Tauri 窗口 / 托盘 / 插件管理窗 / updater / 单实例锁），供版本发布前人工核对。
> 配套用户向文档：[USER_GUIDE](./USER_GUIDE.md)（模型服务/技能/插件管理章节）。
> 每项标注对应实现位置与自动化测试（如有），便于失败时定位。
>
> 维护：改动对应原生面时同步本清单（随批纪律）。

## 1. 启动与单实例锁（222 号）

| # | 步骤 | 预期 |
|---|---|---|
| 1.1 | 正常启动应用 | 主窗口出现，引擎按所选后端拉起（状态栏「实时」绿点） |
| 1.2 | **再次启动第二个实例** | 第二实例立即退出，已有窗口被聚焦到前台（单实例锁，`tauri_plugin_single_instance`） |
| 1.3 | 关闭主窗口（macOS ⌘W） | 应用入托盘保活（非退出）；再次点击 Dock/托盘恢复窗口 |

## 2. 托盘（TrayController，main.rs）

| # | 步骤 | 预期 |
|---|---|---|
| 2.1 | 查看托盘图标 | 图标可见；有未读通知时显示徽标（TrayBadge） |
| 2.2 | 托盘菜单逐项点击 | 菜单项动作正确（打开主窗 / 插件管理… / 退出） |
| 2.3 | 托盘「插件管理…」 | 打开独立插件管理窗（与 cmd_open_plugin_manager 同一入口 `open_manager_window`） |
| 2.4 | 托盘「退出」 | 应用幂等清理后退出（引擎进程随行终止，无残留） |

## 3. 插件管理窗（settings.html，plugin/commands.rs）

| # | 步骤 | 预期 |
|---|---|---|
| 3.1 | 打开管理窗 | 窗口出现并列出已装插件（`list_plugins`）；已连接服务显示指标入口 |
| 3.2 | 安装插件（选择目录） | 权限审批列出声明能力；安装后列表刷新（`install_plugin`） |
| 3.3 | 启用/禁用切换 | 切换生效（`enable_plugin`/`disable_plugin`）；禁用的插件执行被拒 |
| 3.4 | 执行插件命令 | `execute_plugin` 返回结果或明确错误；连续失败达阈值自动禁用 |
| 3.5 | 卸载插件 | 目录删除（`uninstall_plugin`），列表移除 |
| 3.6 | 指标面板 | `get_plugin_metrics` 显示次数/耗时/失败数 |

## 4. 引擎双后端与更新（supervisor/updater）

| # | 步骤 | 预期 |
|---|---|---|
| 4.1 | 设置切换引擎后端（rust/node） | 引擎按所选后端重启（166 号双资产通道 + 健康预检） |
| 4.2 | 检查更新 | shell 与 engine 通道各自检查（`cmd_check_updates`） |
| 4.3 | 应用引擎更新 | 更新落盘后按新版本重启引擎（`cmd_apply_engine_update`） |
| 4.4 | 诊断面板 | `cmd_get_diagnostics` 显示引擎后端/端口/版本（排查入口） |

## 5. 多项目工作区（workspace）

| # | 步骤 | 预期 |
|---|---|---|
| 5.1 | 创建/切换/删除工作区 | 命令族 `cmd_*_workspace` 行为正确，项目列表随工作区切换 |
| 5.2 | 向工作区添加已有项目 | 不产生重复条目（`cmd_add_project_to_workspace`） |

## 6. 已知不在人工范围的面

- 插件系统语义：见 [plugin-system.md](./plugin-system.md)（WASM 沙箱/进程隔离双路径）；
- 引擎 REST 面：由双引擎活体差分器（46 对照）与双套件 smoke 覆盖。
