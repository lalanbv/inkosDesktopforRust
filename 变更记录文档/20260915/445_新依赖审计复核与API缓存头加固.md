## 2. 顺带坐实并修复：API 响应缺缓存头 → 浏览器启发式缓存陈旧遥测

走查 RunLogPanel 时发现面板间歇消失（同 URL 同参数偶发渲染偶发缺席）。定位：**引擎全部 API 响应无 `Cache-Control` 头**——浏览器对无验证器的 200 可启发式缓存，跨走查会话（同 127.0.0.1:8787、不同项目根）的陈旧 `run-log` 响应（如空 entries）会被当新鲜复用，命中 `payload.entries.length === 0` → 整卡不渲染。Performance API 实测组件 fetch 200 + DOM 缺席并存坐实。

修复（系统性而非逐端点）：`server/mod.rs` 路由层新增 `api_no_store` 中间件（`Cache-Control: no-store`），在 `router()`（最内层，覆盖 utility 四路由+测试路径）与 `router_books` 尾部（最外层组合器，覆盖全部合并路由）双层挂载——`Header::insert` 替换语义保证不重复。
