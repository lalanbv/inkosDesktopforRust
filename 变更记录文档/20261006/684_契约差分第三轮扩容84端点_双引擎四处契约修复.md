## 四、真 bug 四处（扩容的直接战果）

1. **中文书名导出 500（TS）+ obs-text 头（Rust）**：books export 的 `Content-Disposition: attachment; filename="${artifact.fileName}"` 对非 ASCII 文件名（中文书名=产品主路径）——TS 裸模板串让 undici 在**响应头物化**时抛 TypeError，路由 try/catch 不在场（毒化发生在 handler 返回后），onError 的 `c.json` 复用已损响应缓存再抛，最终 500 空 text/plain 连 JSON 错误体都发不出；Rust `HeaderValue::from_str` 放行 obs-text（raw UTF-8 字节，`to_str()` 失败，严格客户端拒收）。**修复=双端统一 RFC 6266/5987**：ASCII 兜底名（`[^A-Za-z0-9._-]+` 连续段折叠单 `_`）+ `filename*=UTF-8''`（encodeURIComponent 逐字节镜像，保留 `-_.!~*'()`），值域恒 ASCII。TS 侧三处接入既有 `attachmentDisposition`（books/asset-library/projects export；连带修掉 projects export quoted-string 内 percent 编码浏览器不解码的既有 bug）；Rust 新增 `attachment_disposition` + `ENCODE_COMPONENT_SET`（percent-encoding crate）。红绿：studio 新测试 stash 往返（旧码 500→新码 200）+ Rust e2e 活体（ToStrError→ASCII 恒可 to_str）+ e2e_write_next_contract 两处断言跟进新形态。
2. **researchSearch `allowPrivateEgress` 整键缺失（Rust，数据丢失级）**：TS schema `z.boolean().default(false)` 字段，Rust `parse_research_search` 漏投影——GET 形状漂移 + **PUT 往返把用户显式配置的 635 号 SSRF 私网豁免静默清除**。修复=解析/缺省两分支都带键 + 布尔校验镜像；红绿=contract-diff run-1 分歧 + 双单测（往返保真/缺省形状）。
3. **analytics `avgWordsPerChapter` 舍入差**：Rust 截断除法 61 vs TS `Math.round` 62（61.5 形态，run-1 活体捕获）。修复=f64 除后 `.round()` 镜像 + 单测。
4. **services/models/custom 模型卡缺 `contextWindow`**：TS `ProbedModel` 恒带（未配置默认 0），Rust 条件插入/漏投影。修复=恒投影 + 注释钉 probe.ts 同源。

## 八、教训

1. **差分器盲区即兼容性债，扩容本身就是开发**：36→84 的四个月窗口攒出 4 个真分歧（1 个数据丢失级、1 个主路径 500）——护栏的覆盖面审计要像代码审计一样周期化。
2. **探测→入列→豁免备案协议一等公民化后，盲区再扩张的成本=一条命令**；临时手搓协议不固化就会断代。
3. **响应头物化错误会毒化 Hono 错误通道**（onError 的 c.json 复用已损响应缓存再抛）——头值必须值域恒 ASCII，非 ASCII 走 RFC 5987 双保险，别依赖框架兜底。
4. **cargo test 过滤是子串非正则**；stash 往返证红时若测试与实现同文件，测试会一起被带走——同文件场景用「先测后修」时序证红（books_routes 形态）或活体差分输出作证（analytics/researchSearch 形态）。
5. **e2e 断言旧契约形态的测试是契约变更的连带面**——改形状必须 grep 断言面（content-disposition×2、researchSearch 默认形状×1），testgate 拦截是设计行为不是误红。
