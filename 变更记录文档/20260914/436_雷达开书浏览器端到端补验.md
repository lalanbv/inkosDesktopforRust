## 顺带修复：walkthrough-mock toolCallId 撞确认卡锁

首建失败（题材缺失）修复 fixture 后重发，确认卡秒显「已执行」且无确认按钮、
无执行痕迹——定性为 **mock 伪象非产品缺陷**：mock 每轮返回固定
`toolCallId: "call_propose"`，前端确认卡锁定键 `resolvedProposals[execId]`
（execId 派生自 toolCallId）跨提议撞锁，复用首轮"已执行"状态。真 LLM 每次
tool call id 唯一，不会发生。修复：mock 改 `call_propose_${++SEQ}` 逐次唯一
（已入库）。修复后确认链一次通过（第 7 环）。

## 非缺陷观察（备案）

- IAB 后台页 CSS 动画冻结：`fade-in` 容器计算 opacity 恒 0、Playwright
  actionability 卡死——后台标签页动画时间不推进所致，前台浏览器 0.5s 完成，
  用户路径不受影响（242 号"预览遮罩残留"同类观察）。走查用 DOM `.click()`
  或 CUA 坐标绕过。
- 首轮执行失败（题材缺失）后确认卡仍标「已执行」——`deriveResolvedProposals`
  按后续存在任务执行即判 confirmed，不区分成败；错误另有任务卡展示可感知。
  轻微 UX 瑕疵，涉确认卡状态机，留待独立批次（真实反馈驱动）。
- 引擎默认 `INKOS_BUILTIN_GENRES_DIR=assets/genres` 是打包布局路径，仓库根
  无此目录——开发态走查须种子项目级 genres/（本批已入配方清单）。
