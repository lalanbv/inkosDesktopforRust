## 重要澄清：duel 全红的"假回归"形态

新 checkout/worktree 直接跑 `cargo test`，9 个 strangler duel **秒级全挂**（1.65s vs 正常 43s）——duel 基架以 `packages/studio/node_modules/.bin/tsx` 拉起 TS sidecar 真实进程（strangler_duel.rs:241），**依赖 pnpm install 先行**；缺依赖时全部 duel 快速失败，极易误判为"双端 parity 回归"。与既有备忘互为镜像：缺 `INKOS_DUEL=1` → 假绿，缺 node_modules → 假红。同理，cli-integration/publish-package 依赖 `packages/cli/dist` 与 core dist 先行构建，缺构建产物也是级联假红。判据：秒挂 + 失败面=全部用例 → 先补环境再复跑，别急着定性。
