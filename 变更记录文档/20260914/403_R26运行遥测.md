## 交付

### A. 契约层（第 32 守门域）

`run-log` 双端 1:1（TS `packages/core/src/utils/run-log.ts` +
RS `engine-rs/src/utils/run_log.rs`）：

- `RunLogEntry`：ts（ISO UTC）/ agent / model / durationMs / ok /
  attemptIndex（链内序号，0=primary）/ round（1 起）/ tookOver /
  errorKind（`transient`|`fatal`|null）——**只记元数据，绝不记
  prompt/正文/错误原文**（v5 隐私红线；错误原文走 inkos.log 的 R25 通道）；
- `RunLogBuffer`：环形缓冲，append 超限逐出最旧；`totalAppended` 累计
  含被逐出；默认容量 200（v5 规格）；
- `projectRunLog(snapshot, limit?)`：聚合 total/kept/tookOverCount/
  failureCount + limit 截尾（取最近 limit 条，时间升序；非正/缺省全量）；
- `globalRunLog`：进程级单例（TS 模块常量 / RS `OnceLock<Mutex>`）。

共享向量 `golden/run-log-vectors.json`（Python 独立实现）：append 逐出
（capacity=3 追加 5 → 保留末 3、total=5）+ 投影 4 例（全量聚合/limit=3
截尾/空快照/limit=0 全量语义）。TS+Rust 首跑全绿。

### B. 接线（双端调用缝）

- **TS** `model-chain.ts`：`runAndRecord` 包装每轮 `run`——直通分支
  （零配置）同样记录；tookOver 与 R25 接管成功日志同口径
  （`attemptIndex > 0 || round > 1`）；errorKind 用 `isRetryableLLMError`
  分类。粒度=链内一轮（provider 层同模型瞬态重试在轮内，不另计）。
- **Rust** `agent_router.rs` `chat` 循环：Ok/Fatal/Transient 三分支各自
  `record_run_log`（`Instant` 计时；took_over 同口径；Fatal=非瞬态不切换）。
  行为零变化——R25 既有 10 个 agent_router 行为测与 TS 链行为测 7 例全绿。

### C. 端点 + 面板

- GET `/api/v1/run-log?limit=N` 双端（TS studio server 动态 import 单例 /
  RS `ops_routes::get_run_log` 读全局缓冲；Mutex 中毒回退空快照）。
  纯读、无 bookId、无落盘。
- `RunLogPanel` 挂 Dashboard（WritingStatsCard 后）：聚合行（累计/失败/
  接管）+ 最近 50 条（时间/agent/model/耗时/状态徽标/接管徽标带链序号与
  轮次）；空缓冲整卡不渲染。
