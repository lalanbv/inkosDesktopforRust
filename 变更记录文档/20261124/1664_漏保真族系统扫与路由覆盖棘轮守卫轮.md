## ③ 盲区探活打出的错误协议缺陷

- **修（TS 单侧，对齐 Rust）**：`POST /books/:id/chapters/:num/workspace/inspiration` 在书/章目录不存在时，此前 `readdir` 的 ENOENT 落进外层 catch = **500 裸字符串**；Rust 的 `resolve_chapter_file` 返回 None = **404「Chapter not found」**。TS 对齐为 404（ENOENT/ENOTDIR 映射空目录，其余错误照抛）。

- **立案（双腿同形的历史欠账，非合并丢失；改动须双端同步）**：
  1. `PUT .../workspace/brief` 对**不存在的书**返回 200 并落盘（幽灵书写入）。Rust `put_workspace_brief` 同形。
  2. `POST .../versions/:versionId/restore` 非法版本号 → 500 裸串，而同 id 的 GET → 404。Rust `internal_error` 同形（忠实移植 1.x）。
  3. 「LLM 未配置」三种形态并存：`/books/create` 400 `LLM_CONFIG_ERROR` 信封（global `onError` 已有该映射，但多数处理器自带 try/catch 把它变成 500 裸串）；`translations/:id/run` 500 `INKOS_TRANSLATION_ACTION_FAILED` 信封。
  4. `POST /play/runs/:worldId/:runId/generate-image` 缺 work → 400 裸 ENOENT 串（应 404；Rust 对照未做）。
