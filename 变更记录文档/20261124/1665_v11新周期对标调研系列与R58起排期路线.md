## 关键结论

- **新周期换轴**：从「补功能」转到「守住已写出来的东西 + 让测试咬得住」。1640–1664 的 23 个非规划轮里 9 轮以审查、修复、回座为主，且有数据丢失级缺陷（1648 合并重编号丢章、1649 重排恒等成员文件永久丢失）。
- **数据面三处不可逆硬删（已对到行）**：
  - 「驳回」无确认（`BookDetail.tsx:1225`）直接回滚；回滚链对被废章的正文、草稿 `remove_file`、快照目录 `remove_dir_all`，错误以 `let _ =` 忽略（`engine-rs/src/state/manager.rs:500-547`）；状态快照不含章正文，管线新写章不入 `.versions`，被驳回后正文没有任何存档路径。TS 腿同形（`packages/core/src/state/manager.ts:683`）。
  - 「删书」整目录 `remove_dir_all`（`books_state_routes.rs:320`）；TS `rm(recursive, force)`（`server.ts:8607`）。回收站、版本、快照、export-save 产物一并消失。
  - 删最新章是相对安全的路径（正文 rename 进 `chapters/.trash/`），但无恢复端点、无保留期。
- **漂移缺陷一枚**：Rust 版本 id 正则缺 `structure`（`chapter_workspace.rs:83`；TS `chapter-workspace.ts:23` 有），结构操作写入的存档（`chapter_structure.rs:428`）在 Rust 腿列不出、恢复不了（`parse_version_id`，`:269`）。
- **产品面两处在位未接线**：事实模型早有 `valid_from_chapter / valid_until_chapter`（`runtime_state.rs:252-258`），但 Rust 归约器改事实时直接删旧值（`reducer.rs:395-402`）、投影不按有效期过滤（`projections.rs:314`），TS 腿却过滤了（`state-projections.ts:100-101`）；敏感词函数带 `custom_words` 参数，两个生产调用点都传 `None`（`merged_audit.rs:69`、`write_next.rs:920`），TS 腿整个没有敏感词检查面。
- **验证面零工具**：全仓 manifests 对变异测试、属性测试、覆盖率工具零命中；`docs/DESKTOP_WALKTHROUGH.md` 把 Studio Web 层列为「已知不在人工范围的面」，该前提已被 1650 号对话框族证伪一类；壳侧无任何下载、拖放、剪贴板处理器，导出下载在真壳内零取证。
- **外部对标要点**：Tauri/wry 至今无跨平台静默打 PDF（wry#707，2022-09 开、仍 Open）；tauri-driver 不支持 macOS，官方路径是 WebdriverIO 内嵌 provider（`tauri-plugin-wdio-webdriver`，2026-05 创建、稳定版 1.5.1）；系统回收站跨平台不可靠（Obsidian 已知缺陷、tauri-apps/tauri#5680 自 2022 年开放至今）；Scrivener 默认关闭项目即备份且仅留 5 份；cargo-mutant 支持 `--in-diff` 增量变异。
