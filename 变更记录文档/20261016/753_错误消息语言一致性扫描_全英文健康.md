## 二、错误消息语言扫描

- **engine-rs server 路由层**：错误消息**全英文**
  （"Failed to create story directory" / "Chapter not found" /
  "Invalid chapter number" 等）——语言一致 ✓。
- **studio server (TS)**：`c.json({ error: "..." })` 提取，同样英文主导。
- **前端处理**：`use-api.ts` 的 `localizeKnownRuntimeMessage` 对已知
  错误消息做**中文化映射**（英文→中文），未知的英文错误消息原样
  展示（技术用户可接受）。

**结论**：错误消息语言一致性**健康**——引擎层全英文、前端已知消息
中文化、未知消息英文透传。**无需修复**。
