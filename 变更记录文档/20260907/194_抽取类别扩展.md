## 一、变更内容

### 背景

192 号 backlog 第 4 项：抽取 prompt 的类别固定为 worldview/character/plot/style 四类，而网文系列的高价值迁移设定（宗门势力、法宝、重要场景）没有归属。本批扩到 7 类并同步 UI。

### 引擎（engine-rs）

1. **`server/series_backfill_routes.rs`** `build_extraction_prompt`：类别清单扩为 `worldview / character / plot / style / faction / item / location`，并附一句中文释义（faction=势力组织，item=关键物品法宝，location=重要地点场景）；抽取条数指引 6-12 → **8-14**（类别变多给余量）。
2. **测试**（+1）：prompt 必须含全部 7 类、条数指引与 canon 文件内容。

### Node 回退端（server.ts）

3. extract prompt 同句式同步（双端一致）。

### Studio 面板

4. **`SeriesBackfillPanel.tsx`**：
   - 分组逻辑抽为导出纯函数 `groupBackfillItemsByCategory` + 常量 `BACKFILL_CATEGORIES`（as const）——未知类别仍归 `other` 并**垫底**（此前 other 按出现序混排）；
   - 类别分组标题**本地化**：`t("backfill.category.*")`，类型收窄为 `BackfillCategory` 联合（模板字面量可赋给 `StringKey`）。
5. **i18n**（+8 键，zh/en）：worldview=世界观、character=人物、plot=情节、style=文风、faction=势力组织、item=关键物品、location=重要地点、other=其他。
6. **测试**（+2）：七类各归位 + 未知类别垫底；空输入返回空。

### 兼容性

- `SeriesBackfillItem.category` 本就是自由字符串（schema 不限定），旧草稿/旧文件无需迁移；
- 渲染面（render_backfill_markdown / parse_backfill_items / merge 语义）不受类别数影响；
- 未命中新类别的极端情况照旧落 other。
