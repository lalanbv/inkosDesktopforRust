## 一、变更内容

### 背景

179 号分解文档将「时间线节拍生成端点」列为待产品决策项（暂不实现 / 设置项默认关闭 / 默认开启）。本批次按**最保守可回退**方案落地：**书籍级设置项，默认关闭**——能力就位但不改变任何现有默认行为；若用户最终选择「暂不实现」，移除成本低（默认关 + 独立端口装配）。

### 引擎（engine-rs）

1. **`models/book.rs`**：`BookWritingConfig` 新增 `auto_timeline_beats: Option<bool>`（camelCase `autoTimelineBeats`，缺省省略）；serde roundtrip 测试。
2. **`models/timeline.rs`**：新增纯函数 `merge_chapter_beats` —— 命中既有 cell 原位替换、否则按章号升序插入、未知 plotline id 忽略、空 title/note 净化为 None、有落格时刷新 `updatedAt`。三个单测。
3. **`agents/timeline_settler.rs`**（新模块）：
   - `TimelineBeatsChat` 端口 trait + `BeatsRequest`（章号/标题/梗概/线条名册/语言）；
   - `build_beats_prompt`（中英双语，只输出纯 JSON，只允许名册内 id，未推进的线不输出）；
   - `parse_beats_json` 宽松解析（剥围栏、过滤未知 id 与空节拍）；
   - `RouterTimelineBeatsChat` 生产适配器（AgentRouter 泛化 chat，`inspiration` 档位、温度 0.3、max_tokens 1500）。
   - 5 个单测（prompt 双语、围栏容错、过滤、结构性垃圾拒绝）。
4. **`pipeline/timeline_settle.rs`**（新模块）：`settle_beats_for_chapter` 编排——无 timeline.json / 无线条 → 静默跳过（`Ok(None)`，**不发起 LLM 调用**）；坏载荷 → Err 交调用方告警；LLM 失败 → Err 透传；落盘风格与 PUT 路由一致（pretty + 尾换行）。5 个单测（tempfile 真盘）。
5. **`pipeline/write_next.rs`**：`WriteNextCtx` 新增 `timeline_beats: Option<&dyn TimelineBeatsChat>`；主流程末尾（通知/webhook 之后）新增 **6c 步**——`writing.autoTimelineBeats == Some(true)` 且端口在位才触发；**失败仅 `tracing::warn!`，不影响已落盘章节**（对齐「通知失败不阻断」先例）。3 个全管线测试：开启→沉淀落盘、LLM 失败→管线照常成功、默认关→端口零调用。
6. **生产装配**：`build_write_next_ctx` 改 async 并安装 `RouterTimelineBeatsChat`（Box::leak 静态端口，与既有九路端口同风格）；6 处调用点补 `.await`（books_routes/book_create/ops_routes/agent_production/sub_agent_tool/bin）。新增 wiring 测试断言端口在位（「测试传参 ≠ 生产传参」教训的针对性防护）。
7. **端点**：`GET/PUT /api/v1/books/:id/timeline-auto-beats`（books_state_routes.rs + **生产路由 server/mod.rs** + 测试路由双注册）。PUT true → 写 `writing.autoTimelineBeats:true`；PUT false → 删键（writing 空则整体移除）；GET 返回 `{enabled, bookEnabled}`。3 个端点测试。

### Studio（packages/studio）

8. **core zod**：`BookConfigSchema.writing` 增加 `autoTimelineBeats: z.boolean().optional()`。
9. **Node 回退端**：`server.ts` 同名 GET/PUT 端点（语义与 Rust 逐字对齐，含删键/空 writing 移除/404 面）；server.test.ts 端点测试（默认关、roundtrip、删键、404）。
10. **BookDetail.tsx**：工具栏新增「节拍自动沉淀」开关按钮（审查按钮与删除按钮之间，Waypoints 图标 + 状态圆点；开启=primary 高亮）；乐观切换、失败回滚；i18n 键 `book.autoBeats` / `book.autoBeatsHint`（zh/en）。
