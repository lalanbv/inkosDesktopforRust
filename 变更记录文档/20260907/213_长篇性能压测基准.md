# 213 号：长篇创作（50+ 章）性能压测面——60/500 章两档基准，结论无缺口

- 推送核验：origin/develop 仍停 6bc65564——**201–212 十二提交均未推送**；本批次后本地领先 13。两项默认值无新答复。

## 一、压测设计

196 号基准只覆盖纯函数热路径（title_dedup/resolve/paragraph_scan/chapter_index），从未验证**真实书籍规模**的端到端表现。本批用合成书（每章 3000 中文字 + index + timeline + runtime run/trace 工件）压两档：

- **60 章书**（3.1MB，targetChapters 500 的进行中形态）
- **500 章书**（12MB，极端长篇）

生产形态 engine bin 直启 + 预热一次后取稳态（每端点 3 次）。

## 二、基准结果（M 系列 arm64）

### 60 章书

| 端点 | 稳态 |
|---|---|
| books 列表（逐书聚合 chaptersWritten） | 1.8–2.3ms |
| 书详情（含 60 条 chapters 数组） | 2.2ms |
| timeline（2 线 × 60 cells） | 0.9ms |
| 单章读取 | 0.8ms |
| doctor（LLM 探测 + bookIssues 逐书 index） | 1.1–1.2ms |
| analytics（60 章真实聚合） | 0.7ms |
| export TXT（542KB） | 3.4ms |

### 500 章书

| 端点 | 稳态 |
|---|---|
| books 列表 | **8ms**（冷读 275ms = 磁盘 page cache，非计算） |
| 书详情（500 条 chapters） | 10ms |
| timeline（500 cells） | 2.8ms |
| analytics | 1.6ms |
| doctor | 2.1ms |
| export TXT（4.5MB） | 20ms |

### 拆解验证

500 条 index JSON 解析 ~0.3ms/次——list_books 逐书聚合非瓶颈。

## 三、结论

**长篇性能面无缺口**：500 章极端规模下全部读面/导出面/分析面稳态 <25ms，远低于可感知阈值。196 号热路径基准 + 本批规模基准双层覆盖。

**观察（非缺陷，不预优化）**：`list_books` 每次全量读各书 index 聚合 chaptersWritten——单用户桌面「数百本书且各数百章」的极端组合才会显化（500 章 × 10 本 ≈ 80ms）。当前规模无感，若将来书架规模增长可加 index 摘要缓存（mtime 键）。
