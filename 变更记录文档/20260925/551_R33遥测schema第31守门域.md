## 三、教训与备案

1. **serde_json Value 对象是 BTreeMap（字母序）**——键序断言在 Rust 侧必须排序比对（JSON 对象键本无序）；TS 侧 Object 保序是语言实现细节不是契约。跨端 golden 断言的"序"只在数组上成立。
2. **消费面决定依赖位**：pi-telemetry 原语被 core 源码直接 import，即从传递依赖升直接依赖（511 号依赖使用面审计口径）；精确 pin 0.87 与 pi 双包同版本线。
3. **span schema 的属性取舍**：RunLogEntry 九字段不全入属性——durationMs/ok 由 span 时长与 status 天然承载，重复入属性=双事实源。映射表逐行判定"镜像/承载/扩展"是 schema 设计的关键步骤。
4. **双向避让先例**：R38b 提交信息主动备案"packages/core 冻结"顺延其 TS 面，本项目写档三查让号改 551——并行会话冲突的解法不止改号，还有范围互斥声明（提交信息即协调信道）。
5. R33 收口后 v6 路线剩 R32（压缩对齐，与 R36 树化预研协同）与 R30b（compat 正统化，删除时钟盯上游 ModelManager 迁移动态）。
