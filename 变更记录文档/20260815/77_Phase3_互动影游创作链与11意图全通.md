## 三、parity 要点

1. **双代理单确认**：一次确认两个 LLM 代理（五节创作 → graph 编剧）——进度消息四条逐字（spec/五节/graph/隐式 fallback）。
2. **fallback 不 fail**：graph JSON 解析失败只降级（进度提示 + 最小可玩图），任务仍 completed——TS 语义（玩家总能得到可玩图）。
3. **story-graph.json 路径与 outDir 解耦**：saveStoryGraph 固定 interactive-films/{projectId}/，而五节 Markdown 落在 outDir（默认同名目录）——TS relPath("interactive-films", …) 逐字。
4. **GRAPH_JSON_SHAPE 常量**：系统提示词内嵌完整 JSON 形状示例——LLM 输出契约与 zod schema 同源。
5. **requiredSection 兜底**：四节提取失败回退整体 Markdown（不因小节标题漂移丢内容）。
