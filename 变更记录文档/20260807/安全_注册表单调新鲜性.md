# 安全：注册表单调新鲜性（防重放降级，闭环 R6）

> 日期：2026-08-07
> 范围：`src-tauri/src/commands/registry.rs`、`src-tauri/Cargo.toml`
> 触发：security-reviewer R6（签名重放/降级）——此前评估「需 MITM + 单调时间戳改造」暂缓，本 slice 正式闭环

## 缺陷（R6）

`fetch_registry_index` 验签注册表字节签名，但不校验**新鲜性**。攻击者 MITM 注册表通道（配置层用 http:// 或持有合法证书）可重放**旧** `registry.toml + .sig`——签名仍验证通过，旧注册表列旧版本插件（可能有已知漏洞），用户被诱导降级安装。

## 修复（单调锚 + 时刻比较）

**单调锚 = 本地缓存**：缓存即「上次已验签接受的注册表」，天然单调。新拉取的 `generated_at` 比缓存的更旧 → 判重放/降级 → 拒绝并回退缓存（不覆盖）。

- **`is_registry_downgrade(new, cached) -> bool`**：纯函数决策（可单测）。`chrono` 按**实际时刻**比较 `generated_at`（RFC3339），兼容任意时区偏移（对齐「最佳兼容性」目标）。
- **`read_cached_index`**：读缓存 TOML → 解析 → 取 generated_at。
- **`fetch_registry_index`**：fresh 成功后先查 `is_registry_downgrade`，命中则 `return Ok(cached)`（回退更可信的缓存）；否则接受 + 覆盖缓存。
- **非对称 fail-open**（经 rust-reviewer 对抗验证收紧）：缓存**无锚**（冷启动 / 双方都缺时间戳）或 `generated_at` 非 RFC3339 → 返回 false（不阻断可用性，仅依赖签名防伪造）；但缓存**有锚**而新索引**缺** `generated_at` → 判降级（拒）——防重放「合法签名但无时间戳」的旧格式注册表绕过单调性。冷启动（无缓存锚）fail-open。

## 依赖

新增 `chrono = { version = "0.4", default-features = false, features = ["std"] }`（无 clock 平台依赖，仅 std + 解析）。`parse_from_rfc3339` 在 std feature 下可用。

## 覆盖边界（诚实）

- 防：**重放比已见过更旧的**注册表（核心降级场景）。
- 不防：重放**同份**注册表（相同 generated_at）——benign（无降级）；冷启动首次拉取（无锚，依赖签名 + https）。
- 不防：publish-plugin 工具目前**不设** generated_at（index 级字段由注册表发布者另填）——本机制对有 generated_at 的注册表生效，无则 fail-open。完整闭环需发布者约定生成 generated_at。

## 测试（6，bin crate）

`is_registry_downgrade` 纯函数：更旧→拒 / 更新→受 / 相同时刻→非降级 / 缺新时间戳→fail-open / 缺缓存锚→fail-open / 非 RFC3339→fail-open / **跨时区偏移按实际时刻比较**（13:00+02:00=11:00Z vs 12:00Z）。

## 验证

- `cargo clippy --all-targets -- -D warnings`：clean（chrono 0.4.45 编译）
- `cargo test --bins downgrade`：bin crate 测试 **7 passed / 0 failed**（含 6 个降级判定）
