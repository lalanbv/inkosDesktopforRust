# 插件市场：多版本注册表后端

> 日期：2026-08-07
> 范围：`src-tauri/src/plugin/registry.rs`、`src-tauri/src/commands/registry.rs`
> 目标：放宽 id-唯一约束，支持同 id 多版本（发布方提供版本历史；配合自动更新启用锁定/回滚）

## 变更

- **`plugin/registry.rs`**：
  - `validate` 移除 id-唯一校验——同 id 允许多个条目（不同版本）。TOML schema 不变（仍是 `[[plugins]]` 列表），仅语义放宽，故 `REGISTRY_FORMAT_VERSION` 维持 1。
  - `find_latest(id) -> Option<&RegistryEntry>`：同 id 条目中 semver 最高者。
  - `find_version(id, &Version) -> Option<&RegistryEntry>`：精确版本（锁定/回滚指定版本用）。
  - `latest_compatible(host_version, host_abi) -> Vec<&RegistryEntry>`：每 id 取最高**兼容**版本，id 字典序稳定排序（browse 一个插件只展示最新可用版）。
  - 移除旧 `find(id)`（首匹配，多版本下语义模糊）。
- **`check_updates`**：改用 `find_latest`（比较 installed vs 注册表最高版）。
- **`cmd_fetch_plugin_registry`**：改用 `latest_compatible`——browse 返回去重后的每插件最新兼容版。
- **UI 无需改**：命令返回去重后的最新版，市场列表天然每插件一条。

## 设计

- **版本解析**：`find_latest`/`find_version`/`latest_compatible` 用 semver 比较；版本不可解析的条目跳过（不 panic）。
- **`find_version` 是版本选择器 UI 的地基**：未来前端可列某插件的全部版本、让用户锁定/回滚到指定版本，命令复用现有 `download_verify_extract`（信任链不变）。
- **去重稳定**：`latest_compatible` 用 `sort`+`dedup` + max_by，结果 id 字典序，UI 稳定。

## 验证

- `cargo clippy --all-targets -D warnings`：clean
- `cargo test`：lib **379 passed / 0 failed**（+`test_multi_version_find_latest_and_compatible`：多版本允许、find_latest 取最高、find_version 取指定、latest_compatible 去重；`test_find_by_id` 重命名为 `test_find_latest_by_id`）+ 全集成 0 失败

## 后续

- **版本选择器 UI**：市场条目展开某插件的全部版本（`find_version` 配合一个 list-all-versions 方法），让用户锁定/回滚。当前 browse 只展示最新版（`latest_compatible`）。
