# 插件市场：版本选择器（锁定/回滚指定版本）

> 日期：2026-08-07
> 范围：`src-tauri/src/plugin/registry.rs`、`src-tauri/src/commands/registry.rs`、`src-tauri/src/main.rs`、`src-tauri/picker/settings.html`
> 依赖：多版本注册表后端（`87028d33`）

## 变更

消费多版本地基，端到端启用版本锁定/回滚：

- **`plugin/registry.rs`**：`find_all_versions(id) -> Vec<&RegistryEntry>`——某 id 全部版本，semver 降序（最高在前）。
- **`commands/registry.rs`**：
  - `cmd_list_plugin_versions(id)`——返回某插件全部版本（降序）。
  - **重构**：提取 `fetch_registry_index(url, pubkey, client)` 共享 helper，`cmd_fetch`/`cmd_check`/`cmd_list` 三命令共用（消除 fetch 闭包三处重复）。
- **`main.rs`**：注册 `cmd_list_plugin_versions`。
- **`settings.html`**：市场条目加「其他版本」按钮 → `toggleVersions` 展开/收起 → 列全版本（每行版本号 + 「安装此版本」）→ 复用 `installFromRegistry`（信任链不变）。首次加载后仅切换显隐。
- i18n zh/en（`other_versions`/`install_this`/`no_other_versions`）；renderMarket 重构为 li 列布局（顶行 + 版本展开区）。

## 设计

- **锁定/回滚**：版本选择器让用户安装非最新版（回滚到稳定版、锁定已知良好版本）。install 走既有 `cmd_install_from_registry`——download → `verify_bundle`（配置公钥）→ `safe_extract_tar_gz`，信任链与最新版安装一致。
- **DRY**：`fetch_registry_index` 收敛 fetch/check/list 的注册表拉取逻辑（含 `MAX_REGISTRY_BYTES` 限流）单点定义。

## 插件市场特性弧（完成）

浏览（最新版）→ 安装 → 检查更新 → 更新 → **版本选择（锁定/回滚）**。全链路经 Ed25519 验签 + bundle 校验 + 安全解压 + id 白名单 + 下载限流；多版本注册表 + 版本选择器补全自动更新的回滚能力。
