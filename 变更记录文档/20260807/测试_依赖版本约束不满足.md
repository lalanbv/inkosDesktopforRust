# 测试：依赖版本约束不满足边界

> 日期：2026-08-07
> 范围：`src-tauri/src/plugin/registry.rs`（单元测试）
> 目标：补齐依赖解析的安全关键边界覆盖

## 缺陷（覆盖缺口）

`resolve_dependencies` 已测：后序拓扑 + 版本选择、循环检测、依赖 id **不存在**（missing）、钻石幂等。但未测**「依赖 id 存在但版本不满足约束」**——app 依赖 `lib ^1.0.0`，注册表仅 `lib@2.0.0`（`^1.0.0 = >=1.0.0,<2.0.0`，不匹配）。

此场景下 `find_matching` 应遍历所有版本均不满足后返回 `Err`，`resolve_dependencies` 干净失败——而非误装 `2.0.0` 或静默通过。市场安装链安全关键，必须覆盖。

## 变更

新增 `test_resolve_dependencies_unsatisfied_version_constraint`：注册表仅 `lib@2.0.0`，app 声明 `lib = "^1.0.0"` → 断言 `resolve_dependencies` 报错。

## 验证

- `cargo clippy --all-targets -- -D warnings`：clean
- `cargo test --lib test_resolve_dependencies`：**5 passed / 0 failed**（后序+版本选择 / 循环 / missing / **版本不满足** / 钻石幂等）
