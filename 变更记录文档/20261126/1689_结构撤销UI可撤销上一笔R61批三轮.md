## ① 批二缺口补齐：可撤销状态查询端点（双端）

UI 显示「可撤销上一笔」需要状态查询——批二只有 POST（执行撤销）没有 GET（查询）。补：
- core `structureUndoStatus(deps)`：读日志尾笔 + 当前盘面 → undoEligible + 尾笔元数据（lastKind/lastOpId，无日志全 null）。装配测试三条（split 后可撤销/无日志不可撤销含原因/undo 行后不可撤销原因逐字）。
- 端点双端 `GET /api/v1/books/:id/chapters/structure/undo`（TS structureErrorResponse 薄层；Rust StructureUndoStatus serde camelCase + get handler + 路由注册）。

## ② UI（BookDetail）

- **结构操作成功通知带「撤销」按钮**：`runStructureAction` 成功路径通知条加 undoable 标记（文案=「可撤销上一笔结构操作」），通知条内渲染「撤销」按钮（VS Code 文件操作撤销语义：点按钮即回上一笔）。
- **handleUndo**：POST undo → revision 链式回填 + refetch + undoStatus 刷新 + 通知换「已撤销上一笔结构操作。」；失败（409 拒绝原因等）→ 错误条。
- **可撤销状态行**：`useApi` GET 状态 + eligible 时渲染状态行（「可撤销上一笔结构操作（拆分）」+ 撤销按钮；尾笔类型双语名 split/merge/reorder/undo 各有键）；非 eligible 不渲染（无日志静默隐藏）。undoStatus 在结构操作/撤销后刷新。
- i18n 九键双语。
