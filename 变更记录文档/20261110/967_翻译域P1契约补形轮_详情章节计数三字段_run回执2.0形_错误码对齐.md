## 一、改动

- **manifest 章节三字段**（types.rs `TranslationChapterManifest`）：`translatedSegments`
  （serde default 0）、`reviewSummary?`、`observations?`（形同 TS ObservationSchema）
  ——旧 manifest 可读（default），运行时逐章落盘。
- **runner**：每章收尾按译文计 `translated_segments`；审校产出 `reviewSummary` 与
  observations（审校 issues → `{code:"translation-review", summary, evidence:[],
  category:"quality", assessment:"issue"}`，空白问题不产出=TS summary min(1)）；未审校
  章保留既有审校值。
- **run 回执 2.0 形**：`kind`（translation_pending/translation_completed）、`workId`、
  `totalSegments`/`completedSegments`/`pendingSegments`（按 manifest 汇总）、
  `observations`（本次运行全部审校观察）；`reviewSourcePaths` 属审校 2.0（P3）。
- **详情**：已译段数按译文文件**现场计数**（旧 manifest/早于本轮的项目即时正确），
  manifest 章节与 chapters 双处补三字段。
- **错误码**：run 失败 `TRANSLATION_RUN_FAILED` → TS 2.0 `INKOS_TRANSLATION_ACTION_FAILED`
  （技能缺失/运行失败两处）；上游失败 502 分类保留为 Rust 刻意增强（TS 恒 500，备案）。
