## 一、审校 2.0 双段环（review.rs 新模块）

- **段①独立源读**：原文每 16 段一批经 `submit_translation_source_reading` 结构化提交
  （每段一个必填 schema 字段 `segment_{n}_target`+additionalProperties:false+additional
  空串即错 `TRANSLATION_TARGET_EMPTY`）；system/user 逐字（含原文标题
  sourceChapterTitle、requestedIndices、originals 不暴露现译）。
- **段②有源审校**：TS `submitSourcedReview` 等价环（888 号基座复用）——
  `record_review_observation` supporting（宿主按行区间截取 original-i/target-i 源回执
  精确引文，category 必填=TS ArtifactReviewIndex schema）+`calculate_review_values`/
  `calculate_story_interval`（短篇既有通用件）+终提交 `submit_translation_review
  {summary,observationCodes}`（未记录/重复码回喂重试，预算 16 轮）；TS 三条追加
  system（独立评估/先算术/记录指令）逐字。
- **成对引证**：`check_pairs`——issue 级发现须同时引证 original-* 与 target-* 源，
  否则 `TRANSLATION_REVIEW_PAIR_REQUIRED{observationCodes,instruction}` 回喂（记录与
  终提交两处校验）；独立读本是比对辅助、不得作证据（TS 语义）。
- **端点与技能**：审校走 "auditor" 端点（TS `createAgentContext("auditor")`——任务路由
  可为审校独立配模型）；技能经构造时注入（structured 环旁路 chat 出口，968 号同款）。
- **输出**：`{summary, observations}`（Observation 全形：宿主截取引文 sourceRefs）；
  `passed()`=无 issue 级观察（TS 无 passed 字段）——manifest/详情 observations 落盘
  原形（967 号起），runner 报告改 TS 逐字（`## 标题`+`- summary:`+`- code: summary`/
  `- evidence:`/`- source:`+`> 引文`，`- passed:` 行退役）；run 回执 +`reviewSourcePaths`
  （本轮完成有源审校的章译文路径）+回执层 observations 补 scope `chapter:N` 缺省。
- **单轮 JSON 审校退役**：llm_model `review_chapter` 直接委托 review.rs；968 号 mock 的
  审校分支退役。
