## ④ D-N 缺陷修复：用户中止 → 错误级通知（双端通知面分歧）

**现象**（走查活体实锤）：冻结窗口内每次用户中止（stop/换向）后通知徽章 +1（4→5→6、1→2 两次独立观测）——用户主动停止自己的回复，通知中心却收到「聊天任务出错」错误级报告。

**根因**（双端分歧）：
- Rust 引擎对中止轮广播 `agent:error {error:"aborted"}`（agent_route.rs:1419-1429）+ 500 返回；
- Node 回退端同场景广播 `agent:aborted`（server.ts:5702），**不在通知表**（author-report.ts resolveTaskLabel）→ 无通知；
- App.tsx 通知桥消费全局 SSE → `buildTaskReport("agent:error", …)` 命中「聊天任务出错」→ 错误级通知。
- 即：492 号「SSE 终态归一备案」在通知面的用户可见后果，违背 217/624 号「中止 ≠ 失败」语义在通知面的延伸。

**修复**（packages/core/src/utils/author-report.ts，单点）：`buildTaskReport` 对 `event === "agent:error" && error === "aborted"` 返回 null（引擎侧中止标记精确拦截；Node 真实失败的 agent:error 与「aborted by user」类非精确消息不受扰）。

**可证伪验证**（621 号协议）：
- 新测试 `suppresses the abort report…` 在旧码上**精确转红**（仅新断言失败：中止载荷返回了通知对象；7 旧测不受扰）→ 修复后 **8/8 绿**；
- gate:ts 七步修复后复跑全绿（core dist 重建 + studio 全测 + 活体套件）；
- 活体复验（新构建 index-CS8lxCQ5.js + 全新标签页 + 新 fixture）：冻结窗口 send→stop→request_failed 落盘 ✓ + **通知徽章 0→0**（修复前同场景 0→1）✓ + 聊天区零痕迹 ✓（625_dn_no_notification.png）。

**Rust 门禁裁剪备案**（535/621 先例）：本号代码改动仅 packages/core 两文件，零 Rust 改动；Rust 全套门禁已于本号早前对同一 HEAD（beb7c6e7）引擎代码全量跑过（见①），无门禁空窗。

## ⑤ 走查环境伪象排查记录（非产品缺陷，方法论教训入库）

1. **「Session not found: 1790927887094-52b0cq」**：遗留标签页 store 中该会话 isDraft=false（624 会话中已发送过），而本会话开始时重置了 /tmp fixture——「应用开着时服务器数据被换」的环境伪象。排除产品缺陷的证据链：Rust create_session 确实接受客户端 sessionId（session_routes.rs:205-217，timestamp-random 形态过滤）；合法形态探针落盘成功；真实发送未产生 POST /sessions（isDraft 已 false）→ 无会话文件 → /agent 404。同场景真实用户仅在「恢复备份/切换项目根后不刷新」时遇到，属可接受边缘（重试会因 isDraft=false 永久失败直到 F5——备案为乐观更新语义取舍，与 623 号 loadSessionMessages 守卫同类）。
2. **「✗ aborted」复现**：同源于**陈旧 bundle**——遗留标签页用 goto 只改 hash（`/#/settings`→`/#/`）**不重载文档**，整轮走查跑了 624 会话期间的旧构建（index-3IVgERqB.js，非当前 dist 的 index-Bit0RDWt.js），「✗ aborted+幽灵重试」是旧代码预期行为。tab.reload() 加载当前构建后 T3/T4 复验全绿。**教训（623 号「重建 dist 硬刷新」的反面实例）：跨会话复用浏览器标签页做走查，必须先 reload 验证 bundle 指纹（performance resource entries）再开测。**
3. **IAB 工具怪癖**（624 已备案本会话再证）：负载高时 locator click 30s actionability 超时而 dom_cua.click 可达；cua.scroll/dom_cua.scroll/截图在宿主渲染高占用时 30s 超时；get_visible_dom 只含视口内节点；goto 同页仅改 hash 不重载文档。
