## 一、设计裁定（对照既有机制防双真源）

P3-1..P3-5 已交付的机制吃掉了该计划的大半语义，本轮**只补真实增量**，不建第二真源：

| 布局状态 | 归属 | 本轮处置 |
|---|---|---|
| dock / 底部面板开合 | P3-4 `usePerPageVisibility` 按页记忆 | **不捕获不覆盖**（写第二份即双真源，845 号单一真源原则） |
| 面板宽度 | `usePanelWidth` 全局键 | 维持全局共享（唯一可见宽度面板=dock 且仅写作工作区可见，分键无实际收益） |
| 活动栏选区 | preferences `activeNavSection` | 切换时显式写入目标区（保持活动栏与模式一致） |
| **侧面板开合（⌘B）** | 此前是 `useState(true)` **未持久化**（发现的存量缺口） | **迁入 workspaces store 持久化 + 按工作区捕获/应用**（「各自记住」的核心交付） |
| **规范目的地跳转** | 无 | 新增：recents 推导（写作→最近书页/审阅→时间线/分析→雷达（无参恒可达）/影视→film-studio），无记录回落首页不臆造 |

**切换语义**：切出侧捕获当前侧面板开合进原工作区快照 → 切入侧应用其快照（无快照用默认值：写作/审阅/影视=展开，分析=收起）→ 活动栏同步选区 → 专注模式退出 → 跳规范目的地。**同 id 重复切换=状态零改动**（纯导航回主页；测试抓出初版「无快照重放默认值」会重置用户手动 ⌘B 的状态——即回写/重置缺陷，修正为早退）。

**入口三面同源**：⌘⌥1..4（HOTKEY_DEFS 注册表，速查表自动出现）/ ⌘K 命令面板 4 动作（`action.workspace*`）/ 状态栏切换器（StatusBar 左区，aria-pressed 高亮）。
