## 二、勘误正文

860 号 ssrf 行观察项写有「**Node 回退服务器无回环守卫**（fork 默认 Rust 引擎有 170 号守卫），不改」——**该断言错误**，写档时未实读 Node 侧守卫。本轮实读 `packages/studio/src/api/server.ts:2663-2680`：

| 语义 | Rust 170 号（loopback_guard.rs） | Node 守卫（server.ts:2663-2680） |
|---|---|---|
| T1 跨源（Origin 校验） | Origin 存在→host 必须回环，否则 403；`Origin: null` 403 | Origin 存在且非自身非 allowedOrigins→**403 STUDIO_ORIGIN_FORBIDDEN**（2672-2675） |
| T2 DNS rebinding（Host 校验） | Host 剥端口必须回环，否则 403（`host_without_port` :80） | 回环绑定时 Host 非 allowedHosts→**403 STUDIO_HOST_FORBIDDEN**（2668-2671） |
| CORS 放大面 | 守卫关闭时 CORS 也不复活 `*`；回环反射 | **仅已准入源获 CORS 反射**（2680，rejected 请求零 CORS 头） |
| 扩展机制 | `INKOS_ENGINE_ALLOWED_ORIGINS` env 白名单 | `allowedOrigins` overrides（`https://trusted.example` 形，URL.origin 归一） |
| 默认绑定 | 8787 回环 | `bindHostname` 缺省 **127.0.0.1**（2665） |
| 测试覆盖 | 守卫矩阵测试 | flow 测试 63-77 全覆盖（双 403 码/rebinding 形态/Origin:null/放行+CORS 反射断言） |

**结论：双向水位对等（Node 侧甚至多出 Host 域名归一与默认绑定收紧）**。860 号「不改」的结论恰好正确，但依据错误——正确依据是「守卫已对等存在」而非「无守卫故无从改起」。
