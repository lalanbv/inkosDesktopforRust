## 三、方法论发现（重要环境坑）

首跑 91% 请求（239k/261k）收到 **503**，一度疑似引擎限流——排查证实：

- **根因是用户机系统代理**（macOS System Configuration，127.0.0.1:1082）。Python urllib 会采纳系统代理（含 localhost 目标），洪泛 ~594 conn/s 触发代理限流返回 503；
- 引擎自身**从不返回 503**（全仓 grep 证实，route 面无 503 分支）；loopback 守卫是 Origin/Host 判定（403），顺序连发 200 次全 200 亦证无限流；
- **curl 不读 macOS 系统代理**——这解释了为何 curl 冒烟一直正常而 urllib 大规模异常。

**How to apply**：本机做本地服务的 Python 级压测/长稳，必须 `ProxyHandler({})` 禁代理；"引擎返回异常码"先排除代理与守卫（403=loopback 守卫，503=环境代理），再查引擎。
