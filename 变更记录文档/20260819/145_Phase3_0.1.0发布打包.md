## 二、检查中发现并修复的五个问题

### 1. bin health 版本恒报 0.0.1（发布阻断级）
`inkos-engine-server` 的 `AppState { version: env("CARGO_PKG_VERSION", "0.0.1") }` 用**运行时** `std::env::var` 读**编译期**变量——运行时恒 miss，版本恒为 fallback。冒烟实测 `{"ok":true,"version":"0.0.1"}` 证实。修复：`env!("CARGO_PKG_VERSION").to_string()`（编译期宏）。复测 `{"ok":true,"version":"0.1.0"}`。

### 2. TS 编译错误：LengthSpec 重复导入（131 号手误漏网）
`packages/core/src/__tests__/golden-leaf-dump.test.ts` 66/80 行重复 `import type { LengthSpec }`。vitest（esbuild 变换，无类型检查）1859 全绿未拦；`tsc` 构建拦截（TS2300）。**教训：TS 面基线须含 `pnpm build`/typecheck，vitest 绿 ≠ 编译绿。** 修复：删重复行，三包 `pnpm build` 通过。

### 3. pnpm 11 失败 install 清空 node_modules/.pnpm
本机 pnpm 11.9 的 `verify-deps-before-run` 检查失败后回退 `pnpm install` 撞 frozen-lockfile（仓库锁 pnpm 9），副作用清空根 `node_modules/.pnpm`（1012 链接全失）。恢复：`npx -y pnpm@9.15.9 install --frozen-lockfile`（4s 全 reuse 重建，lockfile 零改动）。

### 4. desktop-package-engine.sh PROD 模式潜伏生产 bug（cp -RL 兄弟链接丢失）
pnpm 把包的传递依赖放在 `.pnpm` 虚拟店**兄弟**符号链接（`partial-json` 在 `.pnpm/pi-ai@x/node_modules/partial-json`，非 pi-ai 目录内）。`cp -RL packages/cli/node_modules` 只跟随被拷目录自身链接，.pnpm 上下文截断——产物 `node engine/dist/index.js --version` 实测 `ERR_MODULE_NOT_FOUND: partial-json`。**CI 同路径产出的 engine bundle 在用户机同样会炸**（打包后从未运行验证过）。

修复：PROD 分支改 `pnpm deploy`（官方自包含部署命令，按锁文件部署完整依赖闭包）+ `--config.node-linker=hoisted`（npm 风格提升布局：实测符号链接 2917 → 48，且残余全在 `.bin/` shim，import 解析零符号链接）。脚本内置**打包期冒烟** `node engine/dist/index.js --version`（此类缺陷在打包期即拦截）。dev 分支（符号链接）保持原样。

### 5. tauri bundle 主二进制选错（多 bin 包）
首次 `tauri build` 产出 `Built application at: .../sign-bundle`——.app 的
CFBundleExecutable 是 **sign-bundle**（975KB 的签名工具），主程序 37MB 的
inkos-desktop 完全没进包。根因：src-tauri 是多 bin 包（inkos-desktop /
sign-bundle / publish-plugin 自动发现），tauri 无显式指定时的主二进制解析
取错。此前 CI 从未暴露——`bundle.active: false` 时 tauri-action 只构建
binary 不组装 .app。修复双保险：Cargo.toml `default-run = "inkos-desktop"` +
tauri.conf.json 顶层 `mainBinaryName: "inkos-desktop"`（v2 schema 顶层字段，
bundle 下不合法）。重建后 CFBundleExecutable = inkos-desktop ✓。

另：tauri 的 bundle_dmg.sh（AppleScript 图标排版）在本机失败——改用确定性
`hdiutil create -format UDZO` 直出 dmg（266M，CRC 校验过）。
