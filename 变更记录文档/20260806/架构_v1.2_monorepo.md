## 决策

采用 **mono-repo**：桌面壳（`src-tauri/`）直接建在 fork 仓库根，inkos 留 `packages/`（零修改）。

## 与 v1.1 的差异

| 维度 | v1.1 | v1.2 |
|---|---|---|
| 仓库模型 | 双仓：fresh 壳仓 + inkos submodule | 单仓：本 fork + 桌面壳 |
| inkos 集成 | git submodule @ tag | 仓库根本体（packages/） |
| 上游同步 | fork 纯 fast-forward | `git merge upstream/master` |
| 同步承诺兑现 | fast-forward 零冲突 | "零文件交叉纪律" → merge 近零冲突 |

## 零交叉纪律（关键）

桌面壳产物只进新文件/新目录，永不碰 inkos 的 `packages/`、根 `package.json`、`README*`、既有 `.gitignore`、既有 `.github/`。Rust 忽略用 `src-tauri/.gitignore`（不追加到根 .gitignore）。

## 影响

- M1 计划 Task 1：去掉 `git init`，改为 `git checkout -b feat/desktop-m1`
- M1 计划 Task 3：去掉 submodule，改为仓库根 `pnpm install && pnpm build`；脚本改名 `desktop-build-inkos.sh`；Rust 忽略用 `src-tauri/.gitignore`
- "完美同步"承诺：仍兑现（inkos 源码随上游演进，壳代码独立；同步方式从 fast-forward 改 merge，功能等价）
