## 核心变更

### 1. 用户指南（docs/USER_GUIDE.md）

**完整文档包含**:

#### 系统要求
- macOS: 11.0 (Big Sur)+, Apple Silicon / Intel
- Windows: 10 (1809+) / 11, x64
- Linux: Ubuntu 20.04+ / Debian 11+ / Fedora 35+
- 磁盘空间: 200 MB
- 网络: 首次启动需联网下载 Engine

#### 安装指引
- **macOS**: DMG 安装包 / Homebrew Cask
  - 权限说明: Keychain 访问、文件访问
  - 首次启动绕过未签名警告
- **Windows**: .msi / .exe 安装程序
  - 安装位置: `C:\Program Files\InkOS Desktop\`
  - 用户数据: `%APPDATA%\com.inkos.desktop\`
  - Windows Defender SmartScreen 处理
- **Linux**: .deb / AppImage
  - 依赖安装: WebKit2GTK, libssl, libgtk-3
  - AppImage 执行权限设置

#### 快速开始
1. **首次启动**
   - 项目选择器（打开/新建/最近项目）
   - Engine 自动下载流程
   - 下载进度状态栏显示

2. **基本操作**
   - 创建新书（书名、题材、平台、目标章节数）
   - 继续写作（自动规划 → 编排 → 生成 → 审计 → 修订）
   - 查看章节（详情、导出 TXT/Markdown/EPUB）

#### 项目管理
- **项目结构**
  ```
  my-novel/
  ├── inkos.json
  ├── .inkos/
  │   ├── secrets.json
  │   └── engine/
  ├── books/
  └── logs/
  ```
- **切换项目**: 菜单栏 → 文件 → 切换项目 (Cmd+O / Ctrl+O)
- **最近项目**: 最多显示 5 个

#### 自动更新
- **检查策略**
  - 自动检查: 每次启动
  - 手动检查: 菜单栏 → 帮助 → 检查更新
- **更新流程**
  1. 检测新版本弹出通知
  2. 下载进度显示
  3. 重启完成安装
- **更新策略**
  - Engine 更新: 自动替换，无需重启
  - 应用更新: 需要重启
  - 失败回滚: 自动恢复旧版本

#### 故障排查
- **应用无法启动**: 检查系统要求、查看崩溃日志、重置配置
- **Engine 下载失败**: 检查网络、手动下载、使用镜像源
- **Keychain 权限错误**: 解锁 Keychain、系统设置授权
- **项目打不开**: 验证项目结构、修复配置、重新创建
- **更新失败**: 检查磁盘空间、检查权限、手动覆盖安装

#### 高级配置
- **日志级别**: `RUST_LOG=debug` 环境变量
- **自定义数据目录**: `INKOS_APP_DATA_DIR`
- **禁用自动更新**: inkos.json 配置
- **代理设置**: `HTTP_PROXY` / `HTTPS_PROXY`

#### 快捷键
- 通用: Cmd/Ctrl + N/O/S/W/Q/,
- 写作: Cmd/Ctrl + Enter/R/E

#### 附录
- 支持的文件格式（导入/导出）
- 系统限制（章节数、字数、并发任务）
- 性能优化建议

### 2. 快速开始指南（docs/QUICK_START.md）

**5 分钟上手版本**:

#### 安装（单行命令）
```bash
# macOS
brew install --cask inkos-desktop

# Linux
sudo dpkg -i inkos-desktop_0.4.0_amd64.deb
```

#### 首次启动（2 步骤）
1. 选择项目（新建/打开/最近）
2. 等待 Engine 自动下载（进度条显示）

#### 创建第一本书（2 方式）
- 方式一: Studio Chat 自然语言输入
  ```
  创建一本玄幻小说，书名《吞天魔帝》，预计 100 章，每章 3000 字
  ```
- 方式二: 新建按钮表单填写

#### 写第一章（1 键操作）
点击「写下一章」，系统自动完成：
```
规划意图 (30s) → 编排上下文 (10s) → 生成草稿 (60s) 
→ 自动审计 (30s) → 必要修订 (40s)
```

#### 常见问题（5 个）
- Engine 下载失败 → 手动下载解压
- macOS 身份不明开发者 → 右键打开
- Keychain 权限 → 解锁命令
- API Key 配置 → 设置菜单
- 写作速度优化 → 使用 flash 模型

### 3. 故障排查文档（docs/TROUBLESHOOTING.md）

**系统化诊断手册**:

#### 启动问题
- **无法启动**: 崩溃日志检查、panic 信息搜索、常见错误表
- **闪退**: 诊断报告、重置配置、磁盘空间、更新版本

#### Engine 问题
- **下载失败**: 网络诊断、手动下载步骤（3 方案）、国内镜像、代理设置
- **启动失败**: 完整性检查、manifest 验证、手动测试、常见错误表

#### 权限问题
- **Keychain 访问被拒**: 系统设置授权、命令行解锁、重置权限
- **文件读写错误**: 权限诊断、所有权修复、可写性检查

#### 更新问题
- **自动更新失败**: 日志检查、磁盘空间、权限验证
- **更新后无法启动**: 回滚方案、备份恢复、重装上一版本

#### 性能问题
- **卡顿响应慢**: CPU 诊断、日志清理、日志级别降低、模型优化
- **内存占用高**: 内存分布查看、重启释放、并发限制、禁用自动审计

#### 数据问题
- **项目损坏**: JSON 格式验证、手动修复、模板创建
- **章节丢失**: 备份查找、恢复步骤

#### 日志收集
- **完整诊断信息**: 系统信息、应用版本、日志、崩溃报告、配置、Engine 状态
- **详细日志启用**: `RUST_LOG=debug RUST_BACKTRACE=1`
