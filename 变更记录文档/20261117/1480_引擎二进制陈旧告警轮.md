# 1480 号：引擎二进制陈旧告警轮——1479 教训机制化（resource 直跑面守卫）

## 目标与范围

/goal 自主持续开发续轮。巡检未到期（2026-11-17）。1479 双缺陷的深层
定性收尾：正式打包链**无缺陷**（打包脚本自带 engine release 重编），
陈旧面在**直跑形态**——`cargo build --release --bin` 不刷新 tauri 的
resource 拷贝（`target/release/engine-rust/`），release 直跑经
`resource_dir` 可能命中数月旧引擎且零信号（1479 实证 8 月产物）。
本轮把该静默面机制化为**陈旧告警**。

## 实施

①**`engine_bin_is_stale` 纯函数**（可测化）：engine-rs/src 树浅层目录
mtime 汇总（改码必动其所在模块目录 mtime）> 候选二进制 mtime → 陈旧；
源码树/二进制不可达 → false（部署形态静默）。

②**`warn_if_stale` 接线**：`resolve_server_bin` 的 resource_dir 命中
分支调用（app_data 落点不比对——updater 自管新鲜度；dev debug 分支
走 engine-rs/target 自建产物无此面）——命中陈旧即 eprintln 警告
「重跑 desktop-package-rust-engine.sh」。

③**三形态单测**：bin 新（false）/触新 src（true）/src 不可达（false）。
