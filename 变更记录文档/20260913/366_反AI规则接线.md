## 做了什么

1. **G2 层级注册双端**：`rules/`、`experience/` source 前缀 → style-asset
   （20，与写法同层的写作纪律垫底参考层）——沿 330 号纪律第 5 条显式注册，
   golden context-priority-vectors.json tier 组追加 2 例。
2. **composer 注入双端**：`loadRuleExperienceEntries(bookDir)`（沿
   `loadStyleBindingEntry` 零打扰先例）——读 `story/anti_ai_rules.json`
   → `composeAntiAiGuidance`（预防块，source=`rules/anti-ai`）+ 读
   `story/experience.json` → `renderExperienceGuidance`（G13 经验块，
   source=`experience/proven`）→ 并入 enforceContextPriorityOrder。
3. **detection 扫描挂点双端**：runner（review-metrics 沉淀段后）+ Rust
   write_next（落盘前）——读规则表 → `scanAntiAiRules(finalContent)` →
   每命中一条 AuditIssue（category=anti-ai-rule，severity 映射，
   suggestion=replacement）→ **issue 流转 reviser 即完成 fix 消费**（365
   契约的 renderAntiAiFixGuidance 信息经 issue description/suggestion 承载，
   不重复注入 reviser prompt）。失败仅 warn 零阻断。
4. **G13 沉淀链**：经验条目 CRUD 端点（PUT 走 mergeExperienceEntries 同
   文本去重）+ UI「沉淀」表单——/learn 语义的最小可用闭环（作者手录；
   LLM 自动提取留待真实反馈）。
5. **端点五件双端**：GET/PUT `/books/:id/anti-ai-rules`（PUT 全量表+
   逐条校验非法 400）、GET/PUT `/books/:id/experience`（PUT merge）、
   DELETE `/books/:id/experience/:entryId`。
6. **UI**：`AntiAiAndExperiencePanel` 挂书籍详情——规则列表（severity
   着色+启停切换）+ 新增表单（pattern/message/replacement/severity/regex）
   + 经验列表（章号标注/删除）+「沉淀」输入。

## 兼容性决策

- 规则/经验文件放 `story/` 下（随书走、随书备份），不放 .inkos 项目级
  ——355 号口径为「逐书资产」。

  suggestion）已按既有 issue→reviser 链流转，同一信息不双路注入。
