## 做了什么

1. **导出**：`GET /api/v1/backup/export?includeSecrets=0&includeSessions=0`
   ——staging 目录聚合（books/ + inkos.json + .inkos/[secrets 默认排除] +
   prompt/，sessions 默认排除）+ 写 `backup-manifest.json`
   （version/createdAt/generator/scope/fileCount/totalBytes）→
   `buildTarArchive` tar.gz 下载（attachment）。
2. **导入恢复两段式**：`POST /api/v1/backup/import`（raw 包）——
   - `confirm` 缺省=**预览**：{fileCount, overwriting[将覆盖清单], newFiles}；
   - `?confirm=1`：**恢复前自动快照**——将覆盖的现有文件打 tar 留存
     `backups/pre-restore-<ts>.tar`（回滚保险）→ 写回全部条目。
3. **安全三则**（tar-read 承载，386 预研就绪）：条目名拒 `..`/绝对路径
   （400 + 清单）、typeflag 白名单、总解压 512MB 上限；manifest 先验
   version=1 与 generator 前缀。
4. **UI**：`BackupPanel` 挂 Dashboard 顶部——「导出备份」直接下载 +
   「导入恢复」file input → 预览（新增/覆盖计数与覆盖清单）→ 确认恢复。
5. **Rust 侧书面决策**：备份/恢复为纯本地 UI 面功能（引擎不消费），
   按 386 备忘 §4 预授权**仅 TS 承担并记录**——Rust 端点不镜像。
