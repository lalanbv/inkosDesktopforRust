## 做了什么

1. **层内确定性排序器**（`context-ranker.ts` / `context_ranker.rs`）：
   - 得分 = clamp01(recency)×wR + clamp01(frequency)×wF +
     clamp01(hookBonus)×wH，4 位小数；默认权重 0.5/0.3/0.2（可配）；
   - `rankWithinTier`：score 降序稳定（同分保持输入序，禁 localeCompare）；
   - `rankEntriesForComposition` / `rank_context_sources`：G2 层间 precedence
     **降序**（对齐 330 号事实 100 在前）之上层内 rank；无特征条目 score=0
     保持既有组装序——无特征时与 enforceContextPriorityOrder 输出序一致；
   - debug 分 `rankScore` 随条目携带（trace/context log 消费）。
2. **summaryEntries 特征填充双端**：章摘要条目 rank.recency=近因（10 章
   窗口线性衰减）、rank.hookBonus=钩子动静（promise-ledger 强度）。
3. **openingHint 双端**：`buildOpeningHint`（上章结尾承接约束：显式指令 +
   结尾摘录 ≤200 码元取尾部；空/首章零打扰）；composer 组装新条目
   `story/chapters#opening_hint`（G2 注册 book-memory 双端）。
4. **压缩留痕双端**：`ChapterTrace.compression.sourceTokens`（压缩前逐
   可压缩源 token 估算 [{source, tokens}]）——TS zod + Rust
   TraceSourceTokens；组装点填真实估算。
5. **golden**：`context-ranker-vectors.json`（rankWithinTier×3 +
   composition×1 + openingHint×3）；TS `golden-context-ranker.test.ts`（3
   用例）与 Rust `golden_context_ranker_diff.rs`（3 差分）读同文件全绿
   （第二十一守门域）。**golden 分数须带小数点**（serde_json Number 0 ≠ 0.0）。

  skip_serializing_if）：无 rank 时排序行为与旧版逐字节一致；

  切换到 rankEntriesForComposition。
