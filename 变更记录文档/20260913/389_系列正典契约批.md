## 做了什么

1. **series-canon 双端契约**（`packages/core/src/utils/series-canon.ts` +
   `engine-rs/src/utils/series_canon.rs` 1:1 镜像）：
   - `parseSeriesCanonFile`：`.inkos/series/{seriesId}.json` 解析——
     version=1 / seriesId 整包校验（非法返回 undefined）；条目逐条校验
     非法跳过（name 空跳、kind 非法兜底 other、关系 target 空跳、
     name ≤80/aliases ≤10×60/summary ≤300/facts ≤10×200/关系 ≤10 note
     ≤200 截断）；产物按 name 码元序。
   - `mergeCodexLayers`：双层合并——book 同名条目**覆盖** series 条目
     （覆盖即省略，精确 name 匹配）；幸存 series 码元序；book 原样。
   - `renderSeriesCodexBlock`：「## 系列实体卡（跨书正典——遵循正典
     事实）」双语块（zh 头/en 头 "Series entity cards (cross-book
     canon — follow canon facts)"，体例与实体卡一致）。
   - `isValidSeriesId`：snake_case slug（`^[a-z0-9_]{1,64}$`，禁空格/
     连字符/大写——对齐 362 号资产 id 命名规范）。
   - 条目与 EntityCodexCard 同构（kind 沿用名册五枚举，事件类条目落
     "other"，零新枚举）。
2. **共享 golden 第 27 守门域**：`series-canon-vectors.json`（seriesId
   6 例/parse 5 例含 315→300 与 213→200 精确截断/merge 3 例/render 3 例
   双语）——TS `golden-series-canon.test.ts` 4 断言 + Rust
   `golden_series_canon_diff.rs` 4 测试读同一文件，**首跑零漂移**。
3. **导出**：core index.ts 增 series-canon 导出块（SERIES_CANON_VERSION/
   四函数/两类型）。
