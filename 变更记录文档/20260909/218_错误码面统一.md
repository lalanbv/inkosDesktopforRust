## 一、缺口与修复

Rust 聊天 Err 分支恒返回 500 `AGENT_SESSION_FAILED`，与 TS `formatAgentFailure`（`classifyAgentFailure` 四类分类）不符。补齐：

- `classify_agent_failure`：busy → llm → internal → unknown 顺序判定，三组正则逐字移植（busy/llm/internal 词表见 studio server.ts）。
- `format_agent_failure`：busy → 409 BOOK_BUSY；llm → 502 AGENT_LLM_ERROR；internal → 500 AGENT_INTERNAL_ERROR（文案按语言改写 `InkOS 内部流程错误：…` / `InkOS internal pipeline error: …`）；unknown → 500 AGENT_ERROR。
- **传输层词汇补录**：TS llm 正则收录 Node fetch 词汇（fetch failed/ECONNREFUSED 等），Rust 传输层为 reqwest——按 205 号 `TRANSIENT_TRANSPORT_PHRASES` 先例补 `error sending request`/`operation timed out`/`connection reset`/`connection closed`/`broken pipe`/`socket hang up`，保证「LLM 不可达 → 502」的**意图等价**（逐字移植下 Rust 错误文本落 unknown/500，分类失效）。实测验证：LLM 不可达（mock 指向 127.0.0.1:9）现返回 502 AGENT_LLM_ERROR。
- action 面 `format_agent_action_failure`（busy→409/其余→502 AGENT_ACTION_FAILED）与 生产任务 busy 正则复用同一 busy 正则，不变。
- abort 分支（217 号）的 500 AGENT_ERROR 与 unknown 类产物一致，不变。
