## 产物结构（最小 4-part OOXML，条目序固定）

```
[Content_Types].xml   ← rels/xml 扩展默认 + document/styles 主件 mime Override
_rels/.rels           ← officeDocument 关系 → word/document.xml
word/document.xml     ← Title(书名)/Heading1(卷)/Heading2(章)/Normal(正文段) + sectPr(A4+1英寸页边距)
word/styles.xml       ← Normal/Title/Heading1/Heading2 四样式 + docDefaults rFonts eastAsia=SimSun
```

- 双端容器同为 **method-0 stored**（Rust `StoredZipWriter` EPUB/MdZip 同款；TS jszip `compression:"STORE"` 显式声明——md-zip 腿 jszip 默认 DEFLATE 的不对称在 docx 面修正）。
- 施工图 §1.4#1 的 mime 串**不进 parse**（仅 content_type 响应头）：TS GET 面无 mime 归一（cast 直通），Rust parse 加别名即双端漂移——有意收敛为短名 `"docx"`。

## 纯函数四对（golden `chapter-docx-vectors.json`，16 向量 + 3 静态 part sha256 锚，TS 生产派生）

| 函数对 | 语义 |
| --- | --- |
| `docx_escape_xml` ↔ `docxEscapeXml` | XML 五实体转义（& 最先防二次转义） |
| `docx_body_paragraphs` ↔ `docxBodyParagraphs` | 非 `#` 行 trim 非空各一段——与 EPUB `markdown_to_simple_html` 行语义一致（同书双格式分段一致）；施工图三对外加的一对（切段是行为语义面，防双端调用方各自实现漂移） |
| `docx_paragraph_xml` ↔ `docxParagraphXml` | (styleId,text)→`<w:p>`：pPr 样式引用 + run 级 rPr eastAsia（不依赖 styles 继承链）+ xml:space="preserve"；空文本=无 run 空段 |
| `docx_document_xml` ↔ `docxDocumentXml` | (书名,卷表,章+段)→完整 body：章序=(卷 order（未分组/未知=0 前置，与 md-zip `00_ungrouped` 桶序一致）,章号) 稳定排序；卷桶首章前发 Heading1；未分组章直排不造卷标题（docx 无目录树语义——与 md-zip `00_ungrouped` 目录形态有意不同，写入断言说明） |

- XML 纪律：属性序固定（双端同序=字节可比）、无缩进无注释、UTF-8 无 BOM。
- 三常量 part（Content_Types/rels/styles）双端字面镜像，sha256 锚进向量文件（Rust 差分测试对拍）。
