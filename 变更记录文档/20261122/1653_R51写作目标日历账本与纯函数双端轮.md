## 数据模型定案（施工图 §2.2 的形态收敛）

- **账本行 = 四键 `{ts, chapterNum, before, after}`**（ts=UTC ISO——写入端零时区换算）；**dayKey 全部由消费端计算后入参纯函数**（`dayKeyOf`/`todayKey`）——「dayKey 入参」的施工图原文形态：纯函数不吃时区环境、多设备各自本地视图（月历「用户看自己当地日」）、双端引擎零时区依赖（Rust 无 chrono 需求）。施工图行形态五键案（dayKey 写入行）被有意收敛为四键+消费端计算。
- 落点 = `{bookDir}/.inkos/writing-log.jsonl`（书级 .inkos 子目录新形态；双根对称：Rust `books/{id}/.inkos/`、TS `works/{id}/source/.inkos/`）。
- 追加语义 = 读旧+拼接+原子写（append-only 语义与原子性两全——章保存频率下 O(n) 重写可接受）；读取宽容（坏行跳过）；仅元数据无正文（隐私红线）。

## 纯函数三对（golden `writing-goal-vectors.json`，19 向量，TS 生产派生）

| 函数对 | 语义 |
| --- | --- |
| `daily_word_delta` ↔ `dailyWordDelta` | 记录流+dayKeyOf → 日净增表（升序；负增量=删稿日） |
| `goal_streak` ↔ `goalStreak` | 端点=表内最大 dayKey 逐日回溯（缺日=断链）；今日已达成计入（正向激励）、今日未达/未写跳过不毁（进行中）；非今日未达=断链重置 |
| `expected_finish` ↔ `expectedFinish` | ceil((目标-当前)/节奏) 天 + todayKey 日算术；已达成/零节奏 → None |

- 附 `shift_day_key` ↔ `shiftDayKey`（Rust = 零依赖 civil 日算法 Hinnant days_from_civil/civil_from_days；与 TS Date.UTC/toISOString 等价性由跨月/跨年/闰年向量锁定）+ `localDayKey`（消费端本地日键）。
- golden 语义点：今日未达跳过不毁/今日计入/断链/首日/端点早于今日（gap-resets）/ceil 余数/NaNo 1667 节奏。
