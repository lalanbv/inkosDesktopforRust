## 选题与实现

483/484 号的回退端冒烟原为手工编排（起 mock、起服务器、跑 fixture、逐条 curl 断言），不可重复。本号固化为仓库资产 `scripts/node-fallback-smoke.mjs`：一条命令完成**编排 + fixture 一致性套件 + 回退端特有断言**，全绿退出码 0、任一失败非零。

套件内容（9 断言）：
1. mock LLM 启动、TS 服务器启动（轮询就绪）；
2. `walkthrough-fixture.mjs` 全链（resync → write-next 第 2 章 → 第 3 章压缩留痕 → promises 投影 kinds 齐全 → run-log 计数）；
3. director PUT{patch} 合并 / GET 回读（478 号契约活体断言：keywords/runMode/stage/savedChapters/resumeAdvice）；
4. task-routing PUT/GET 往返；
5. SPA 入口与 API 面 `Cache-Control: no-store`（469/445 号回退端对应面）；
6. run-log 调用计数 > 0。

工程要点：`.bin/tsx` 是 shell 包装不能直接喂 node（SyntaxError）——用 `node_modules/tsx/dist/cli.mjs` 真实入口；`--keep` 保留临时根供人工排查；服务器 SIGTERM 自清理。

## 用途

- 回退端（TS server）相关改动后一条命令回归；双引擎兼容性的可执行护栏（与 check-routes.mjs 同级的机械门禁）；
