# 489 号：部署级真缺陷修复——桌面默认引擎 0 内置技能/0 内置题材

日期：2026-09-16　分支：develop　基线：f3638852（487 号）

## 缺陷坐实（488 号差分器发现的深挖）

- TS 回退端 /skills 列出 **16** 个内置技能（packages/core/skills，15 目录 + 嵌套发现）；/genres 列出 **15** 个内置题材（packages/core/genres）+ 项目级；
- Rust 引擎 /skills 仅 **1**、/genres 仅 **2**（项目级）——根因链：引擎内置根 = `INKOS_BUILTIN_SKILLS_DIR`/`INKOS_BUILTIN_GENRES_DIR` env 或 `assets/{skills,genres}` 相对 **CWD**；桌面壳 `rustbin::build_launch` 只注入 PORT/PROJECT_ROOT/STATIC_DIR 且 cwd=用户项目根（`assets/*` 必缺失）、Rust 引擎打包脚本也只打包二进制+static——**桌面默认引擎 0 内置技能/0 内置题材**，agent 技能面与题材模板静默缩水（Node 回退端经 core 相对锚点反而齐全）。

## 修复（三层）

1. **`src-tauri/src/engine/rustbin.rs`**：新增 `resolve_builtin_asset_dirs`（resource_dir/engine-rust/{skills,genres} 优先、dev 回退 packages/core/{skills,genres}，**两目录双在才注入**——半套不如不注入）；`build_launch` 增参注入 `INKOS_BUILTIN_SKILLS_DIR`/`INKOS_BUILTIN_GENRES_DIR`；既有 2 单测更新 + 新增 2 单测（注入/缺省双态 + 双目录同时在场才解析）；
2. **`src-tauri/src/main.rs`**：接线 resolve → 注入，缺失时 eprintln 提示重跑打包脚本；
3. **`scripts/desktop-package-rust-engine.sh`**：打包补拷 `packages/core/{skills,genres}` → `engine-rust/{skills,genres}`。
