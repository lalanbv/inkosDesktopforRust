# 514 号：vite 哈希资产不可变长缓存——回退端重载性能优化

日期：2026-09-16　分支：develop　基线：d5571eca 之后系（513 号文档对齐后）

## 缺陷与修复

`/assets/*`（vite 构建产物，**内容哈希文件名**）此前无任何 Cache-Control 头——浏览器每次 reload 对 js/css/png 全量条件回源。SPA 入口已 no-store（483 号），资产本应配对走**不可变长缓存**（内容哈希变名 → 名字变即内容变，可放心永久缓存）。

修复：`/assets/*` 响应补 `Cache-Control: public, max-age=31536000, immutable`——用户重载只回源 555B 的 index.html，全部 hash 资源走本地缓存；发版后新 hash 文件名天然失效旧缓存。
