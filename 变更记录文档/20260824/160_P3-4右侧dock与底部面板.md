# 160 号变更:P3-4 右侧 dock 与底部面板

- 日期:2026-08-24
- 模块:packages/studio
- 类型:工作台深化功能(151 号 P3 第四工作包)
- 关联:157~159 号(P3-1..3)

## 一、基础设施

- **M `hooks/use-panel-width.ts`(参数化)**:`options {min; max; defaultWidth; storageKey; side}`——默认行为不变(左侧 180~400);右侧 dock 用 280~700 + 独立键 + `side:"right"`(宽度=视口右余量)。纯函数 `clampPanelWidth/readStoredPanelWidth` 增边界参数;测试 +1(自定义边界)
- **N `hooks/use-per-page-visibility.ts`**:面板开合**按页记忆**——单 JSON map(`inkos:studio:<name>-visibility`)存各页开关;`defaultValue` 支持差异化默认(dock 书页默认开=沿袭旧 BookSidebar;底栏默认收起);**toggle/setVisible 按有效值(含默认)翻转**(曾出缺陷:按 false 起算导致默认开的面板首击"没反应",e2e 插桩定位后修复);测试 2 用例(解析/降级)

## 二、ContextDock(右侧)

- **N `components/ContextDock.tsx`**:BookSidebar 泛化——
  - **面板注册表** `CONTEXT_DOCK_PANELS`:进度(ProgressSection)/大纲(ChaptersSection)/设定(Character+Foundation)/摘要(SummarySection),堆叠渲染,后续可分 tab 化(P4 评估)
  - 宽度拖拽(280~700,双击复位,`side=right` 右余量算法)+ `inkos:studio:dock-width` 持久记忆
  - 顶栏(上下文标题 + 关闭钮);artifact 视图(真相文件/章节阅读编辑)原样保留(经 BookSidebar 导出复用)
  - 可见性由 App 持有(Cmd+Shift+D 分发 + 按页记忆)
- **M `components/chat/BookSidebar.tsx`**:导出 `PanelView/ArtifactView` 供复用;本体保留为旧轨(P4 走查后随双轨清理删除);App 书籍页挂载由 BookSidebar → ContextDock(mobile 浮层 BookSidebarToggle 不变)

## 三、BottomPanel(底部)

- **N `components/BottomPanel.tsx`**(Cmd+J,App 分发+按页记忆):
  - **两 tab**:生成任务流(直接复用 `ToolExecutionSteps` 组件,数据源同为 chat store 激活会话的 toolExecutions——`collectRecentExecutions` 纯函数收集最近 40 条)/ 日志(`/logs` 轻量内嵌,LogViewer 同款数据面与配色)
  - **常规高 240px(<40% 视口高,不挤压编辑区),最大化 70vh** 可切换
  - **滚动跟随**:默认贴底;用户上滚离底 >40px 自动暂停,回底自动恢复;工具钮可手动切换(aria-pressed)

## 四、App 接线

- `HOTKEY_DEFS` + `mod+shift+d`(dock)/`mod+j`(底栏);速查页自动出现
- 书籍页 ContextDock 替换 BookSidebar;主列 `</main>` 后挂 BottomPanel(全局所有页可用)
