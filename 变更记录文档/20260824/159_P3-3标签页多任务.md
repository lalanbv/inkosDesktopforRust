## 一、纯函数层(TDD 先行,14 用例)

- **N `lib/tabs-reducer.ts`**:
  - `TabState {id; route; title; pinned; preview}` / `TabsSnapshot {tabs; activeId}`
  - `routeKey(route)`:标签身份键——同书不同章是不同标签、import 不同 tab 不同标签、无参页按 page
  - `tabsReducer` 动作:open(preview|sticky)/activate/close/closeOthers/pin/retitle/hydrate
  - **VSCode 式预览语义**:预览打开原位替换(激活的是预览→原位;游离预览→复用;无→追加,全程唯一预览标签);粘滞打开命中已有标签(含预览)→激活并转正;pin 双效(转正+置顶标记);close 激活位移右邻→左邻→null;closeOthers 保留目标+已固定
  - `sanitizeTabsSnapshot`:持久化恢复清洗(坏条目丢弃/重复键去重/悬空 activeId 回退末位)
  - 20 标签 fuzz:开关交替后不变量(activeId 空或指向现存标签)

  - 书名回填 effect:/books 到达后对书相关标签 retitle(深链先开时标题回退「书籍」的问题)
  - `HOTKEY_DEFS` 生成式追加 `mod+1..mod+9` → 按序激活标签;速查页自动出现 9 条

## 五、调试过程中发现并修复的缺陷(备案)

1. **深链 effect 吞标签切换**:初版 effect 以 view≠route 为触发条件,标签切换天然造成该分歧 → 激活后被"开回" hash 路由。修复=依赖仅 routeKeyJson(见上)。经 e2e 插桩(DISPATCHED 标记)定位。
2. **深链标签标题回退**:effect 首跑早于 /books 返回,书标签标题落「书籍」→ retitle 动作 + 回填 effect。
3. 既有地雷「同 hash 重复赋值不触发 hashchange」由"store 为真相"架构正面化解:渲染不依赖 hashchange,hash 仅作深链入口。
