## 二、缺口 A：suppressProductionTools 硬剔除（agent_route.rs）

- `PRODUCTION_MUTATION_TOOL_NAMES`：TS 13 件全集的**可注册子集**（9 件）——fanfic_create/continuation_import/spinoff_create/imitation_create 在 Rust 不作为 agent 工具注册（propose→confirm 生产链），无需列入。
- 注册面：`find_active_running_task` 命中（同会话后台生产运行中）→ `strip_production_mutation_tools(&mut tools)` 从工具表 retain 剔除。read/ls/grep、material 双件、research、propose_action、forecast、play 与 TS 一致保留。
- 分发面：`ChatToolRouter.suppress_production: bool`——true 时名单内工具返回 `Unknown tool` 错误文本（防幻觉调用绕过剔除表）。
- 单测：`strip_production_mutation_tools_keeps_readonly_set`（19 件 schema 进，9 件生产工具出，10 件只读/非生产面保留）。

## 三、缺口 B：resync_chapter_state 工具（book_edit_tools.rs）

- schema 逐字对齐 TS `ResyncChapterStateParams`（bookId?/chapterNumber?/allowNewHooks?）；注册 book/edit 会话（TS edit 过滤器不剔除 ✓）。
- 实现：`resolve_tool_book_id` → 缺省最新章（TS `index[last].number`）→ 复用 `run_resync_chain`（51 号链，改 pub(crate)）→ **新审计**复用 `run_audit_flow`（audit_route）→ 按 auditDraft 语义回写索引（状态 ready-for-review/audit-failed + `[severity] description` 问题行 + updatedAt）→ 漂移指引 `persist_audit_drift_guidance`（改 pub(crate)，critical/warning 过滤，失败不阻断）→ 双语摘要 + `{kind: "chapter_state_resynced", ...}` details。
- **allowNewHooks 旋钮双端穿透**（B 的前置——Rust 仲裁器原缺此参）：`hook_arbiter::arbitrate_runtime_state_delta_hooks` 加 `allow_new_hooks: Option<bool>`（`Some(false)` 时新候选在准入评估前拒绝，reason=`new_hooks_disabled`，已知名单 upsert 与 mention/resolve/defer 不受影响，逐字对齐 TS `hook-arbiter.ts`）→ `build_runtime_state_artifacts{,_from_snapshot}` → writer `build_runtime_state_artifacts_if_present`（+`#[allow(clippy::too_many_arguments)]`）→ `SettleChapterStateInput.allow_new_hooks` → `SettleRequest`/`SettlementRetryParams`/`TruthValidationParams` → resync 链。repair/revise/settle/write 等其余链路传 None（行为不变；TS repair HTTP 面本也未暴露该参）。
- e2e（mock LLM 全链，books51 harness）：`resync_tool_rebuilds_artifacts_and_audits`——settle 走 WRITER_RESPONSE、validator PASS、审计 1 条 warning → 断言摘要「仍有 1 个问题」、details status=audit-failed、索引 status/auditIssues 回写、audit_drift.md 落盘。
