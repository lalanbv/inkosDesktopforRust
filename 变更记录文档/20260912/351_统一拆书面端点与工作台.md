# 351 号：统一拆书面端点+拆书工作台面板+发布材料池（G5 续，G5 大件收官）

- 日期：2026-09-12
- 类型：双端端点 + studio 工作台面板
- 规划依据：[328 规划](../20260911/328_对标调研分析与改进规划.md) G5 后半；契约层见 [350 号](350_拆书工作台契约.md)

## 做了什么

1. **聚合纯函数** `buildDeconstructionExport`（双端）：chapters + depth + language +
   topCharacters → 一括产齐 `EvidenceIndex + CharacterDossier[]（full 档，按证据数
   降序取前 N，默认 5）+ PacingStats + 可发布 markdown`。
2. **统一拆书面端点双端** `POST /books/:id/deconstruct`：
   - 入参 `chapters`（DeconChapter 数组，兼容聊天工具/settle 产物）+ 可选
     name/depth/language/topCharacters/publish；
   - 聚合后落盘 `books/{id}/story/deconstruction/{name}.md`；
   - `publish: true` 时同时写入项目材料池 `.inkos/materials/{id}.md` +
     `{id}.json` manifest（对齐 ingest 存储形态；id 规则
     `decon-{bookId}-{name}`，非法字符折叠为 `-`，截断 64），
     产物即可被参考资料绑定与 G1 混合检索召回。
3. **拆书工作台面板（S）** `DeconstructPanel` 挂书籍详情：行格式输入
   （章号|出场人物|事件|章型|伏笔动静）→ 分析（档案+节奏+markdown 预览）→
   一键"发布到材料池"。空输入/解析失败给出人话提示。
