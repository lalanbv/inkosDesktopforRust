# 360 号：R3 契约层——质量趋势聚合+回灌幂等+承诺紧迫度（二轮 P0 第三件首批）

- 日期：2026-09-12
- 类型：契约层 + 双端镜像 + golden 差分
- 规划依据：[355 二轮规划 §4 R3](../../开发时SpecCoding'sPlan/inkosDesktop/07_产品演进规划/对标调研分析与改进规划_v2.md)（审查分数沉淀 review_metrics + 趋势聚合；promise-ledger 增目标章窗/紧迫度 0–100/置信度；回灌 contentHash 幂等）

## 做了什么

1. **质量趋势聚合**（新模块 `quality-trend.ts` / `quality_trend.rs`）：
   `buildQualityTrend`——ReviewMetricRow（chapter/overallScore 0–100/passed/
   三档 severity 计数）→ 升序点列 + issueCount + 有分章均值（一位小数，
   缺分不进均值）+ failingChapters。数据源锚定既有 `AuditResult.overallScore`
   （auditor 支持评分时携带，0-100），零新增 prompt 面。
2. **回灌幂等**：`reviewMetricContentHash`——FNV-1a 64 UTF-8 hex16（对齐
   348 号 chunkFingerprint 口径），输入 `chapter|score|passed|critical|
   warning|info` **不含 recordedAt**（重放时间不同内容相同必命中同一指纹，
   对齐 ANWA ChapterArtifactSyncCheckpoint 语义）；`dedupeReplayRows` 同
   指纹仅首次 fresh 保序。golden 含 4 个 Python 预计算 FNV 已知值锚定。
3. **承诺紧迫度**（promise-ledger 双端扩展 `resolvePromiseUrgency`）：
   目标章三级置信度（expectedPayoff 显式提取=explicit 窗±2 章 >
   targetChapters 书末兜底=inferred 窗[当前,书末] > 无=unknown）；WNW
   urgency 映射（remaining ≤0→100 / 1–3→80 / 4–10→60 / >10→40；无目标
   推进中→40、未推进→20；fulfilled→0）；level 阈值 ≥80 high / ≥40 medium。
   None 序列化 skip（对齐 TS undefined 丢键，沿 359 号先例）。
4. **golden**：`quality-trend-vectors.json`（3 trend + 3 replay + 8 urgency，
   共 15 例）；TS `golden-quality-trend.test.ts` 与 Rust
   `tests/golden_quality_trend_diff.rs` 读同文件差分全绿（第十八守门域）。
5. index.ts 导出新 API；bindings 167 文件全绿（+7：PromiseUrgency/
   TargetWindow/UrgencyLevel/UrgencyConfidence/ReviewMetricRow/
   QualityTrendPoint/QualityTrend）。
