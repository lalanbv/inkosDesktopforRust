# 358 号：R2 张力曲线契约层——TENSION_METRICS 解析+章级曲线+启发式告警（二轮 P0 第二件）

- 日期：2026-09-12
- 类型：契约层 + 双端镜像 + golden 差分
- 规划依据：[355 二轮规划 §4 R2](../../开发时SpecCoding'sPlan/inkosDesktop/07_产品演进规划/对标调研分析与改进规划_v2.md)（settle 增记 conflictLevel/revealLevel 入 chapter_summaries + 卷级曲线 + 启发式告警）

## 做了什么

1. **解析**：`parseTensionMetrics`——从 settler 输出提取 `=== TENSION_METRICS ===`
   节（复用 `extract_tag` 先例）；JSON 形态（无锚 ``` 围栏）优先、
   `key: value` 行式回退（兼容中文冒号）；任一字段缺失/非法整节放弃返回
   undefined（不产半截分）；数值 round 后 clamp 1–10。
2. **存储契约**：`StoredSummary` 双端扩可选 `conflictLevel/revealLevel`
   （不入 sqlite——真相源在 chapter_summaries.md，零迁移成本，旧书历史
   markdown 照读）；`renderSummarySnapshot` 四处（TS story-markdown + TS
   analyzer 私有 + Rust story_markdown + Rust chapter_analyzer）8→10 列
   （zh 冲突强度/揭示强度，en conflict/reveal），缺分渲染空单元格；
   `parseChapterSummariesMarkdown` 双端兼容 8/10 列（纯数字 clamp 1–10，
   其余→undefined）。composer 等下游逐字段消费，扩列无感。
3. **曲线聚合**：`buildTensionCurve`——仅收双分齐全的章，章号升序（稳定
   排序，禁 localeCompare）；输出 points + scored/unscored 计数。
4. **启发式告警**：`detectTensionWarnings` 三规则（默认阈值
   `TENSION_WARNING_DEFAULTS`）：flat-middle=中段（ceil(0.3N)–floor(0.7N)）
   conflict 极差窗口 ≥4；climax-crowding=尾段（floor(0.75N)+1 起）reveal≥8
   高点 ≥3 且 > 早段高点数；weak-hook-streak=连续 3 章 reveal≤3。文案双语
   （description+suggestion，对齐 audit issue 形态）。`analyzeTensionCurve`
   一括聚合供端点/面板复用。
5. **Rust 镜像**：`engine-rs/src/utils/tension_curve.rs` 1:1（围栏/尾逗号/
   行式正则逐字对齐 TS tension-curve.ts；复用 settler_parser::extract_tag）；
   StoredSummary 8 处构造点补字段；serde kebab-case 告警枚举。
6. **goldens**：`golden/tension-curve-vectors.json`（6 parse + 2 curve +
   5 warnings，逐组手工锚定边界）；TS `golden-tension-curve.test.ts` 与
   Rust `tests/golden_tension_curve_diff.rs` 读同文件差分，全绿 diff=0。

## 兼容性决策

- 张力分**不入 sqlite**：markdown 真相源单点读写，规避 ALTER TABLE 迁移；
  sqlite 侧 StoredSummary 行构造补 `None` 即可。
- 告警阈值集中在常量对象，端点/UI 均可覆盖（`TensionWarningOptions`）。
