- 规划依据：[328 号对标调研改进规划](../20260911/328_对标调研分析与改进规划.md) Phase B 批次一 G3（ANWA A3 八级分类 + A4 双治理方案采纳）

  表持久化与 scheduler 治理接线为下一批（337 号）。

## 做了什么

1. **八级判定决策表** `resolveQualityVerdict`（顺序即优先级，确定性、无 LLM）：
   过线+义务缺口 → `patchable-obligation-gap`；过线+warning → `continue-with-warning`；
   过线 → `accepted`；未过+义务+结构级 → `draft-obligation-unmet`（重写）；未过+义务 →
   `patchable-obligation-gap`；未过+纯局部 → `local-patch-plan`（修复循环）；
   未过+quality-first → `stop-for-replan`（停在章节边界）；未过+连续债务达上限 →
   `replan-required`；其余 → `defer-and-continue`（记债继续）。
   输入从既有 AuditIssue 两维（severity × repairScope）+ 义务缺口 + 连续债务计数推导，
   与 85 分阈值循环兼容（passed 字段为调用方裁决）。
2. **每书治理方案** `resolveGovernancePolicy`：completion-first（默认，休闲用户友好）/
   quality-first（停在已保存章节边界）；book 级逐字段覆盖 project 级；
   `maxConsecutiveDebts` 缺省 3。
3. **债务记录模型**：`QualityDebt`（id/bookId/chapter/issueCategory/severity/status/
   createdAt/followUpNote）+ 状态机 `transitionDebtStatus`（open→deferred→resolved，
   reopen 回退；非法转换返回 valid:false 不抛错）。
4. **派生口径**：`verdictCreatesDebt`（四种降级/义务判定入账）与
   `verdictContinuesPipeline`（stop/replan/unmet 停在章节边界）。
5. **共享 golden 向量** `quality-verdict-vectors.json`（35 例：决策表 20 例覆盖全部
   八级 + 边界交叉[quality-first 忽略债务计数、治理切换即时生效、局部优先于阈值、
   过线输入权威性] + 治理解析 6 例 + 状态机全矩阵 9 例 + 契约冻结）。TS 断言 5 项 +
   Rust 差分 4 项（第六个共享守门域），单测含"每条规则至少两向量覆盖"自检。
6. **实现中发现并修复**：Rust 差分测试首轮漏读向量的 `.input` 层级（TS 读
   `vector.input.book` 而 Rust 在顶层找）——测试骨架错误，共享向量立即暴露。
