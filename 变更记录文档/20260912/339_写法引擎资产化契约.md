## 做了什么

1. **盘点**：`StyleProfile` 是统计指纹（句长/段长/TTR/topPatterns/rhetoricalFeatures），
   Rust 镜像齐全（style_analyzer.rs / models/style_profile.rs）；imitation 链路靠
   style_guide 全文注入，无特征粒度、无启停、无泄露检测——资产化缺口清晰。
2. **特征池推导** `deriveFeaturePool`：从 StyleProfile 确定性推导特征项——三条
   metric（sentence-length / paragraph-length / vocabulary-diversity，guidance 从
   统计数值生成，如"单句平均长度控制在约 18.4 字"）+ topPatterns 每条
   `pattern:<值>` + rhetoricalFeatures 每条 `rhetoric:<值>`；空列表维度跳过。
3. **启停与组合**：`applyFeatureSelection`——显式白名单优先（给出即只留白名单），
   否则全集剔除黑名单；未知 id 忽略不报错。`composeStyleGuidance` 双语渲染
   （条目上限 12、可截断带省略号），产出可直接注入 writer prompt 的段落。
4. **每书绑定** `StyleBinding`（profileName + enabledIds/disabledIds +
   maxGuidanceChars）+ `resolveStyleBinding`：按 sourceName 命中档案 → 池 → 启停 →
   双语 guidance 段；未命中返回 null。
5. **试写入口** `buildTrialWritePrompt`：绑定 guidance + 前提 + 场景简报 + 目标字数 →
   试写提示词（单 TRIAL_CONTENT 区块、禁止越题/新增具名角色），zh/en 双语。
6. **专名泄露检测** `detectProperNounLeak`（ANWA A9）：参考作品专名在仿写正文中的
   出现计数——大小写不敏感、**长名优先掩码**（防"萧家堡"同时计出"萧家"）、
   minOccurrences 过滤、按次数降序。
7. **共享 golden 向量** `style-feature-engine-vectors.json`（向量组：完整 profile +
   poolIds 顺序、selection 4 例、guidance 双语 2 例、trial 双语 2 例全文、leak 6 例
   [长名优先/大小写/无泄露/空表/minOccurrences 过滤/空正文]、契约冻结）。
   TS 7 项断言 + Rust 差分 6 项（第九个共享守门域）。
