- 日期：2026-09-12
- 类型：契约层 + 双端镜像 + golden 差分
- 规划依据：[355 二轮规划 §4 R4](../../开发时SpecCoding'sPlan/inkosDesktop/07_产品演进规划/对标调研分析与改进规划_v2.md)（题材基底/推进模式/世界样本三库，统一 shape `{id,name,body,expectations,taboos,samples[]}`，导入导出便携 JSON 包，内置种子随包分发）

## 做了什么

1. **统一资产 shape 双端**（`asset-library.ts` / `asset_library.rs`）：
   `LibraryAsset {id(snake_case slug ≤64), kind(genre-base|progression-mode|
   world-sample), name ≤80, body 1–4000, expectations ≤20×200, taboos
   ≤20×200, samples ≤10×600}`——三库共用，非法条目报错不抛错、不截断。
2. **内容指纹幂等合并**：`assetCanonicalForm`（`kind|id|name|body|exp␟连|
   taboos␟连|samples␟连` 单行拼接，分隔符方案免疫 JSON 键序/转义双端差异）
   + `assetContentHash`（FNV-1a hex16，golden 含 Python 预计算已知值×2）；
   `mergeAssetLibrary`——同 kind+id 同 hash 跳过 / 异 hash 覆盖（incoming
   赢，对齐 review_metrics「修订后最新赢」）/ 新 id 追加，产物按 kind+id
   码元序稳定。
3. **便携包导入导出**：`buildAssetLibraryExport`（`{version:1, assets[]}`
   稳定序 + 固定键序；**只锁语义不锁缩进字节**——serde pretty 与
   JSON.stringify(,2) 格式差异非契约）+ `parseAssetLibraryImport`（逐条
   校验非法跳过不阻断、版本不符整包拒绝、产物排稳）。
4. **题材基底种子×3**（随包分发，空库冷启动对策）：都市异能/玄幻修真/
   悬疑刑侦——每个含核心引擎 body、读者期待 expectations×3、禁忌
   taboos×3、写法示例 samples×1；seed 正文是写法契约数据，双端逐字镜像。
5. **golden**：`asset-library-vectors.json`（validate×3 + hash×2 + merge×3
   + package×1 + seeds×1）；TS `golden-asset-library.test.ts`（5 用例）与
   Rust `golden_asset_library_diff.rs`（5 差分）读同文件全绿（第十九守门域）。

## 兼容性决策

- id 用 snake_case 而非 kebab-case（命名规范：禁连字符、优先下划线）。
- 首批只内置 genre-base 种子；推进模式种子随 363 号、世界样本不内置
  （355 号风险对策：导入时落"通用样本≠本书世界"两段式，随 364 号）。
- 本批纯契约层：存储/端点/UI/导演与 BookCreate 挂载全在接线批（363/364）。
