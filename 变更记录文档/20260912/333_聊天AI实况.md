- 日期：2026-09-12
- 类型：引擎增强 + 前端（TS core + studio + Rust 引擎三端）
- 规划依据：[328 号对标调研改进规划](../20260911/328_对标调研分析与改进规划.md) P0 项 G8a（ANWA A8 AI 实况的采纳；PlayHud 模式聊天面轻量版）

## 做了什么

1. **盘点结论**：思考流折叠展示已在此前迭代就位（Rust 129 号 thinking 三事件桥 + TS
   onEvent thinking:start/delta/end 广播 → studio stream-events → parts-builder →
   ChatPage Reasoning 组件 defaultOpen=false）；G8a 真实缺口是**消息级 token 与
   首包/总耗时在双端聊天链路被丢弃**——TS pi AssistantMessage.usage 与 Rust
   StreamedCompletion 的 prompt/completion/total_tokens 都采集了但没进响应面。
2. **TS core**：`runAgentSession` 返回体新增 `usage`（pi usage 权威值 input/output/
   totalTokens）、`thinking`（thinking 块聚合文本）、`timings`（`firstTokenMs`=
   起点到首个 `message_update` 事件、`totalMs`=整轮耗时；subscribe 回调内采样）。
   `AgentSessionResult` 接口同步扩展。
3. **TS studio**：`/api/v1/agent` 主响应透传 `usage/timings/thinking`（thinking 非空
   才带；工具_owned 响应与错误路径不加，对齐既有 response 语义）。
4. **Rust**：`LoopChat` trait 返回三元组带 `LoopUsage`；`LoopOutcome` 新增
   `usage`（多轮累加）+ `LoopTimings`（首个 `on_delta` 记首包）；`RouterLoopChat`
   从 `StreamedCompletion` 取 token 并聚合思考流文本（`Arc<Mutex<String>>`）；
   `agent_route` 成功响应带 `usage/timings`（camelCase 序列化对齐 TS），thinking
   非空才带。`ScriptedChat` 测试 stub 同步签名 + 新增多轮 usage 累加断言。
5. **前端 studio**：`Message` 类型新增 `usage?/timings?`；`AgentResponse` 同步；
   sendMessage 成功路径把实况数据挂到助手消息（finalizeStream 扩展 live 参数 +
   非流式路径内联）；新组件 `MessageHud.tsx`（紧凑单行：↑输入 ↓输出 · 合计 N ·
   首包 x.xs · 总耗时 y.y s，tr 双语，双字段缺省整行不渲染）挂 ChatPage 助手消息尾部。
