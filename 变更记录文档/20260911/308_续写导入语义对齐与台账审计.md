## 一、发现与修正：续写导入的静默追加偏差（303 号执行器语义）

TS `createContinuationImportTool`（agent-tools.ts）：已有书 `existingChapterCount > 0` 且未显式给 `resumeFrom` → **throw**（`Book "{id}" already has {count} chapter(s); resumeFrom is required.`）——防止静默追加破坏既有时间线。

Rust 303 号实现此前为**静默 count+1 追加**，与 TS 语义相反。已修正：

- 已有书 + 有章节 + 无 `resumeFrom` → `Err` 逐字 TS 文案；
- 已有书 + 显式 `resumeFrom` → 按其导入；
- 已有书 + 零章节 + 无 `resumeFrom` → 从第 1 章导入；
- 新书分支补 `assertBookDoesNotExist` 对齐（已存在 → 双语错误）。
