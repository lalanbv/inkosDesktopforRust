## 关键实证结论

- 0.74.2 与 0.73.1 同代（纯 scope 改名踏板可用）；0.87.0 新代+`./compat`
  官方踏板（deprecated 且有删除时钟）。
- 四函数（streamSimple/completeSimple/getModel/getEnvApiKey）0.87 落
  compat；Type/Static/createAssistantMessageEventStream/validateToolArguments
  留主入口。裁决：R30 走 compat 先通、R30b 立案正统化（api 工厂/
  getBuiltinModel），两提交独立回滚。
- 真断裂点四件：StreamFn 参数 `Context`→品牌 `TranscriptContext`（token
  估算 system prompt 计入路径=行为审计点）、事件变体删 text/thinking/image
  增 adaptive、`Model.provider`→ProviderId、传递依赖 +pi-telemetry+chord
  及四家 SDK 大版本跳（audit:npm 复跑）。
- AgentOptions 构造项全保留（超集新增）——本仓 new Agent 三处构造面免改。
