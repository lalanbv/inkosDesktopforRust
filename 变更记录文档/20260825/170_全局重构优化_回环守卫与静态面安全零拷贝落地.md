全局分析（三层架构 + 双端测试基线）与 30 款案例调研后，落地首批高价值改进：**封堵本地引擎服务的浏览器跨源攻击面**（S1/S2，secrets 明文端点 + CORS `*`）、静态面安全头与零拷贝、health 后端标识。

## 代码变更

### engine-rs（Rust 默认引擎后端）

| 文件 | 变更 |
|------|------|
| `src/server/loopback_guard.rs`（新增 ~330 行） | 回环守卫 middleware：Origin/Host 回环判定（localhost/127.0.0.1/[::1]/[::]，端口不限），远端 Origin 与 DNS rebinding Host 403，缺头放行（curl/健康探测/duel 零改动）；env `INKOS_ENGINE_LOOPBACK_GUARD`（默认开，`0/false/off` 关）+ `INKOS_ENGINE_ALLOWED_ORIGINS`（精确白名单追加）。13 个测试锁定行为矩阵（含「拦截响应不带 CORS 头」「secrets 端点远端 Origin 403 且不泄漏密钥」） |
| `src/server/mod.rs` | 注册模块；`HealthResponse` 加 `backend:"rust-engine"` 字段（加法变更；Node 无此端点=62 号 Rust 超集，无契约破坏面）；health 测试断言更新 |
| `src/server/static_routes.rs` | ① assets + SPA 回退注入 `X-Content-Type-Options: nosniff` / `Referrer-Policy: no-referrer` / `X-Frame-Options: DENY`（API 面不动）；② index.html 缓存 `Vec<u8> → Bytes`——消每请求整页 memcpy（引用计数克隆）；新增安全头测试（含 API 面对照） |
| `src/bin/inkos-engine-server.rs` | 装配守卫层于 CORS 之外（后加 layer 在外，请求先守卫后 CORS） |

### 设计复核修正（诚实记录，防后人重复踩坑）

- **SSE SsePayload Arc 化取消**：axum `Event::event/data` 持有 `Cow<'static, str>`，Arc 化在 yield 处仍须物化 String，每帧 memcpy 次数不变——零收益伪优化（与 02 号 roadmap「serde 栈缓冲 +11% 回退」同类 API 边界结论）。已登记入方案 W-B1。
- 替代落地静态面 `Bytes` 化（真实收益：SPA 每次回退请求的整页拷贝归零）。
