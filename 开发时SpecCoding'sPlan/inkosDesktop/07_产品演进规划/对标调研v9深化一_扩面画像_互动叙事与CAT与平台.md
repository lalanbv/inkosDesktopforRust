# 对标调研 v9 深化一：扩面画像（互动叙事 / 翻译 CAT / 发布平台）

> 日期：2026-11-21 ｜ 主文档：[对标调研分析与改进规划_v9](对标调研分析与改进规划_v9.md) ｜ 字段与判定口径沿用 v8 深化一。

## H. 互动叙事与游戏叙事引擎（5 款）——对应本仓 play/interactive_film 域

> 内部事实基线：本仓 play 域约 7666 行（`play.rs` 1147 / `play_graph.rs` 1333 / `play_parser.rs` 518 / `play_runner.rs` 2562 / `interactive_film.rs` 2106）；StoryPlayer 为图结构播放器（`StoryPlayer.tsx:28-81`：start 节点定位 / `visibleChoices(node, vars)` 条件可见选择 / `visibleDialogue` / ending 判定 / 节点缺失容错）；FilmWizard 为创作向导；work.json 承载图定义。

### H1 Ink / Inky（inkle，开源 MIT；商业游戏成就背书）

- 定位：互动叙事脚本语言事实标准（《80 Days》等获奖作品引擎）；Inky 为官方一体化编辑器。
- 核心机制：①**knots/stitches** 两级组织（大分支=多个 knot、knot 内 stitch，divert 跳转+weave 嵌套收敛）——90k 词级分支脚本的结构纪律；②**glue**（无换行拼接）与 weave 缩进层级实现「分支后自动汇流」；③变量/函数/ tunnel 等编程原语；④Inky 编辑器：语法高亮+**变量实时跟踪**+jump-to-section+TODO 注释+即时试玩。
- 判定：knots/stitches 组织纪律→**改造采**（观察——本仓 play_graph 节点图无层级组织原语，大图项目的「结构纪律」是真实痛点，挂互动影视域数据门控）；glue/weave 收敛语义→**改造采**（同上，与 storylet 合并评估）；Inky 编辑器体验（变量跟踪/jump-to-section）→**改造采**（FilmWizard 增强候选，同门控）。

### H2 Twine（开源，2.12.1，2026-10-06 发布）

- 定位：非线性互动小说工具的大众标准（免费开源，发布为网页）。
- 核心机制：①**passage** 链接式结构（每 passage 一屏正文+链接跳转）——最低创作门槛的互动叙事形态；②**故事格式即引擎**（Harlowe/SugarCube/Chapbook/Snowman 四默认格式，格式=运行时+语法集，可替换）；③**双轨编辑**：可视图（passage 卡片连线）+ Twee 文本标记导入导出。
- 判定：passage 式最低门槛形态→**已对齐**（本仓 FilmWizard 向导+节点编辑覆盖同语义）；「格式即引擎」可替换运行时→**不采**（本仓单运行时 play_runner，多运行时引入维护面无对应用户信号）；Twee 文本互操作→**改造采**（观察——play_graph 与文本标记互转可作导入通道候选，挂门控）。

### H3 Yarn Spinner（开源，3.1，Unity/Godot/Unreal 三端）

- 定位：游戏对话系统标准之一（2026 路线页确认月度更新节奏）。
- 核心机制：①**storylets + saliency**（2025-05 v3 起）：内容片段按**世界状态**（变量谓词）声明可进入性，运行时按 **saliency 权重自动选择**下一个内容——「作者定谓词，引擎选内容」的内容选择层；②smart variables（变量带派生逻辑）、枚举、run-content-once；③3.1（2025-12）：async runner、VM 重写、cancellable actions。
- 判定：storylets+saliency→**改造采**（观察——本仓 `visibleChoices(node, vars)` 已有「变量谓词控制可见性」的雏形，storylet 是把它从「选择内过滤」升格为「内容图全局调度」；对互动影视的导演编排是真增强，挂互动影视域数据门控）；smart variables→**不采**（变量系统已有，派生逻辑属过度设计）。

### H4 ChoiceScript（Choice of Games，开源）

- 定位：多选文字游戏专用语言（2026 发布管线持续：官方 Upcoming Releases 2026 线程、Steam 发行持续）。
- 核心机制：纯文本 `*choice/*if/*goto` 极简指令集 + 状态变量 + 统计型结局（数值比较定结局）。
- 判定：**已对齐或超越**（本仓变量系统+ending 判定+AI 生成图结构远超纯手写指令集的产能形态）；无新增可采项；作「指令集极简主义」的对照锚（本仓不引入指令集语法——图结构 JSON 对 AI 生成更友好，方向正确）。

### H5 Ren'Py（开源，8.6.1「Real Artists Ship」，2026-11-17）

- 定位：视觉小说引擎标准（图形演出向：立绘/CG/音效/转场）。
- 判定：**不采**（图形演出层与本仓文字叙事定位不同轴；本仓互动影视走 AI 生成文面，非立绘演出）；其「剧本即 Python 可编程」路线与本仓「图结构即数据」路线是两条合法路线，维持后者。

## I. 翻译 CAT 域（1 款正式画像 + 标准与惯例）

### I1 OmegaT（开源，omegat.org）

- 定位：开源 CAT 工具标杆（2026 横评仍列免费首选；对照 Trados/memoQ 商业双雄）。
- 核心机制：①**翻译记忆（TM）**：句段级历史库，当前句段与库比对给 **exact（100%）/fuzzy（部分匹配）** 两档建议；②**fuzzy matching**：相似度阈值惯例（行业通用 75%+ 显示，编辑距离/最长公共子序列族算法）；③**match propagation**（匹配传播）：同一句段在多处出现时自动填充一致译法；④**TMX**（Translation Memory eXchange）XML 标准导入导出——CAT 生态互操作事实标准；⑤glossary 术语库独立于 TM；⑥关键词搜索。
- 判定：TM 三层形态（exact/fuzzy/术语）→**改造采**（R56 施工图预备的形态蓝本，见深化三 §2）；match propagation→**采**（同一原文句段一致译法——写作域翻译的本仓场景里与 glossary 强化同向）；TMX 互操作→**改造采**（导入导出各做最小子集，导入落 TM 层不写 glossary）；Trados/memoQ→**不采**（商业闭源，机制已由 OmegaT 覆盖）。

## J. 发布平台写作后台（2 款）

### J1 起点作家助手 NovelBuddy（阅文集团，商业免费）

- 定位：全平台创作应用（Android/iOS/鸿蒙/桌面）。
- 核心机制：流畅创作编辑器 + **可视化统计分析**（创作数据面板）。
- 判定：统计面板→**已对齐或更强**（R13 写作数据面板：产出节奏/审查通过率/token/双曲线同屏）；平台云端语义（发布/签约/收益）→**不采**；无新增可采项。

### J2 番茄作家助手（字节跳动，商业免费）

- 定位：多端写作助手（iOS/Windows/安卓）。
- 核心机制：草稿箱+**定时发表**（最长 N 年）+多端同步+实时本地保存；**错字检测+智能语法检查**；灵感库+写作计划。
- 判定：错字/语法检测→**已对齐或更强**（本仓 review 链=LLM 级审校+错误目录 R7，语义层强于规则层）；灵感库→**已对齐**（市场雷达+导演灵感卡）；写作计划→**已对齐**（R51 立项中）；实时本地保存→**已领先**（原子写 94 站+快照自愈）；定时发表→**不采**（云端发布语义）；无新增可采项。

## §4 简提级

- **Twine 社区编辑器**（VimTwee/VS Code Twee 3 等）：双轨编辑生态证明文本标记路线可行——支撑 H2 判定。
- **INK/inkjs/inklecate**：Ink 的多语言运行时移植族——若未来做 play_graph↔Ink 互操作，inkjs 是浏览器端候选（观察）。
- **ArtiPack/互动叙事模板市场**：无稳定生态，不采。
- **MemoQ/Trados/DeepL 术语表**：商业 CAT 机制已被 OmegaT 覆盖判定，简提不展开。
