## 1. 对标复查结论（2026-09-14）

**webnovel-writer（WNW）**：v6.2.1（2026-07-07）后零发布零提交动静，本轮**无可采新信号**。历史版本中 v6.2.1 的 Windows 文件锁修复（`atomic_write_json` 重试）是唯一未吸收的工程小件——对应本项目持久层原子写（→ R29，P2）。v6.1/v6.2 的 doctor/write-gate/run-ledger/行为评测，本项目已有等价或更强落地（R7 错误目录、R8 行为评测、331 号恢复手册）。

**ANWA**：0.4.20–0.4.24（09-04 ~ 09-13，五天五版）主题为「**可靠性 + 透明性 + 选题闭环**」，逐条判定：

| ANWA 机制 | 本项目现状 | 判定 |
| --- | --- | --- |
| 结构化调用**重试次数 + 备用模型 failover**（0.4.20/21） | 345/346 号按任务模型路由只解析**单模型**；失败即整链失败（仅 planner 有解析层 3-retry） | **真缺口 → R25（P0）** |
| **实况提示词/Token/耗时透视**（0.4.19–21） | R21 ContextLens=装配回放（事前）、R13 面板=章级 token 聚合（事后）；**调用级运行数据（耗时/模型/重试/接管）无记录** | **真缺口 → R26（P0）** |
| **热点选题库 + 一键开书**（0.4.21） | 市场雷达有选题发现+分析（335 号），但**雷达结果→建书无闭环** | 缺口 → R27（P1） |
| **章节目标防复读门**：AI 拒绝与摘要/既有目标相同的规划（0.4.24） | 仅有软提示（「不重复摘要」「禁止总结凑字数」），无硬门 | **真缺口 → R28（P1）** |
| 空响应 JSON 回退（0.4.22–24，DeepSeek 特修） | planner 3-retry+fallback memo、检测链 maxRetries 已等价覆盖 | 已覆盖，无动作 |
| 分任务独立配额（0.4.20） | 本项目本地运行无计费配额语义，token 聚合已有（R13） | 不对标（弃其糟粕：订阅计费） |

**领先项维持确认**：Story Bible 自动沉淀、质量治理八级判定+债务状态机、结构化错误目录、行为评测+LLM-as-judge、ContextLens 装配回放（ANWA 实况透视是运行时视角，与装配回放互补而非覆盖）。

## 3. 五轮路线（R25+）

### P0（可靠性+透明性，对标确定性缺口）

| # | 事项 | 设计要点 | 双端成本 | 验收 |
| --- | --- | --- | --- | --- |
| R25 | **任务路由 v2·失败接管链** | TaskModelOverride 增可选 `retryCount`（1–5）与 `backupModels`（≤3）；新纯函数 `resolveTaskModelChain`：primary + 去重后的 backups（与 primary/前序重复者剔除，总长 ≤4），retryCount 缺省 1=现行为；接线批（下一批）：调用缝按链序 failover，可重试错误（网络/429/5xx/超时）在当前模型重试 retryCount 次后切下一模型；零配置零迁移 | TS+R | golden：chain 解析（满配/继承/缺省/去重/封顶）；接线批补接管行为测 |
| R26 | **调用级运行遥测（Run Log）** | 每次 LLM 调用追加记录（agent/model/耗时 ms/成败/尝试序号/是否接管切换/错误类）；环形缓冲（默认 200 条）+ `GET /api/v1/run-log` 纯读端点；面板挂 Dashboard；与 R25 接管事件联动展示 | TS+R+S | golden：记录投影纯函数；端点快照测 |

## 4. 风险与对策

| 风险 | 对策 |
| --- | --- |
| R25 failover 放大延迟（坏模型重试拖慢） | retryCount 上限 5、backupModels 上限 3；可重试错误白名单（AbortError/ContextWindowExceeded 不重试不切换） |
| R25 备用模型能力差异毁产出 | 接管是**可用性兜底**非质量对等声明：接管事件在 run-log 显式留痕（R26 联动），作者可辨 |
| R26 遥测含 prompt 内容泄漏面 | run-log 只记元数据（模型/耗时/序号/错误类），不记 prompt/正文 |
| R28 相似度门误杀合法回环章节 | 阈值保守起步 + 只重规划一次 + 降级告警不阻断；golden 锁定判定口径 |
| 真实反馈缺位 | R16/R19/R24 维持留白 |
