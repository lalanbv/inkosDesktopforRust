# 对标调研 v8 深化二：按域差距矩阵

> 日期：2026-11-21 ｜ 主文档：[对标调研分析与改进规划_v8](对标调研分析与改进规划_v8.md)

## §1 正文编辑域

- **现状**：`packages/studio/src/pages/ChapterReader.tsx:246` `<textarea>` 纯文本受控编辑；章节读写对照分屏；实体卡有独立 CodexPanel（`components/CodexPanel.tsx`）但编辑器内**无实体命中高亮**；上下文计量徽章（estimate/usage 双源）已挂输入框。
- **对标**：NovelCrafter 编辑器内 Codex 实时高亮+悬停卡+tracking 控制（B1，2026-03 排除短语/大小写条目级治理）；Scrivener Snapshots 内联 diff（A1）；Obsidian Bases 结构化属性视图（A6）；编辑器框架基准——Lexical 大文档键入延迟优 20–40%（E2）。
- **判定**：**部分缺口**——纯文本正典本身是对（LLM 友好/解析稳定/0GC/VCS 友好/双栈差分器根基），缺的是「注解层」而非「编辑器内核」。
- **处置**：**R52**（实体命中高亮 overlay+悬停卡，viewport 裁剪防性能回退；排除短语挂实体卡 tracking）；WYSIWYG 整体替换**不采**（显式裁定，四条理由见深化一 E1/E2）；Bases 式属性视图挂观察清单。

## §2 结构组织域

- **现状**：章节=`books/<书>/chapters/NNNN_标题.md` 文件系统即结构（`state/chapter_filename.rs` 数值识别、正典形态优先）；创建/删除有原子门（chapter delete 三连拒先例）；章快照回滚删除其后产物（`state/manager.rs:468`）；**无卷/幕组织层、无拆分/合并/重排端点**；系列层已有（seriesId→series canon，R20）。
- **对标**：NovelCrafter 2026-09-24 大组织更新——act/chapter/scene 全操作（插入 before/after/in-between、拆分、移动、Outline 折叠）（B1）；Scrivener binder 任意重组（A1）；Manuskript 大纲树（A4）；bibisco 场景一等结构（A5）；Sudowrite Scenes（B2）。
- **判定**：**真缺口 P0**——中文网文百章/千章体量下，「百章平铺」的组织负担与「结构操作只能靠文件改名」的原始形态是日常摩擦最大的面。
- **处置**：**R48**（拆分/合并/重排三操作，乐观并发+原子重编号事务）；**R49**（卷/幕元数据分组层——章挂 volumeId 可选字段+组内排序键，**不移动文件路径**，避开 chapters/ 平铺假设的全体消费者；series canon 同构复用）；场景一等化挂 **R57 数据门控**。

## §3 检索与查找域

- **现状**：G1 混合召回（BM25+向量 RRF+sqlite-vec 升级路径 R12）服务于**上下文装配**（composer 内部）；⌘P 快速打开为标题级（书/章/会话/设置）；**无正文级全局搜索端点与 UI**（服务端路由盘点无 search 路由）。
- **对标**：Obsidian 标题级 switcher+全文检索双轨（A6）；novelWriter 全项目搜索（A3）；SillyTavern Data Bank 文档 RAG 与 Vector Storage 级联（B5）；Tantivy 嵌入库（E6）。
- **判定**：**真缺口 P0 工程小件**——检索内核已在，缺「作者消费面」；这是 30 款里最不对等的一条（最强的装配检索配了最弱的作者查找）。
- **处置**：**R47**（引擎只读搜索端点：BM25 命中+高亮片段+实体/伏笔/设定来源过滤；UI 挂侧面板并扩展 ⌘P 正文命中档）；Tantivy 挂观察清单（chunk 量级门控）；SillyTavern「检索→激活」级联挂观察（R57 评估）。

## §4 导出与发布域

- **现状**：`/api/v1/books/:id/export?format=txt`（`server/books_routes.rs:2672`，含 RFC5987 中文文件名测试）；翻译域 epub 导出（`translation/export.rs` `write_translation_export`）；works 生成物可下载版本（WorkInspector）。
- **对标**：Scrivener Compile（多节合成/格式链/章节过滤/元数据页，A1）；NovelCrafter docx 列表导出（B1，2026-01）；BabelDOC 版式保持（F2）；Ulysses 发布管线（A2，不采）。
- **判定**：**真缺口 P1**——交付面（编辑/平台/存档）只有裸 txt，docx 是中文网文交付与投稿事实格式。
- **处置**：**R50**（批一：Markdown 打包 zip+导出预览；批二：docx——npm 依赖走 audit:npm 闸，分两批降供应链风险）；发布管线**不采**。

## §5 目标与统计域

- **现状**：R13 写作数据面板（产出节奏日/周字数、审查通过率、token 聚合、张力/质量双曲线同屏）；**无目标设定（书目标/日目标/截止日）与达成反馈**；无 streak/日历面。
- **对标**：Scrivener project targets+截止日（A1）；Ulysses goals（A2）；novelWriter 每小时/每日字数直方图（A3）。
- **判定**：**小缺口 P1**——统计已有消费端，缺「目标 vs 实际」的设定与激励闭环；写作应用的目标面是留存/习惯核心（三款独立演进到同一形态）。
- **处置**：**R51**（书级/全局字数目标+达成进度条+写作日历热图；state 面 book.writing 目标键+R13 面板消费；不引入游戏化积分等噪声）。

## §6 版本与快照域

- **现状**：①章快照+回滚（回滚删其后产物，`manager.rs:468/501`）；②恢复前快照兜底（R18，备份域）；③works 生成物版本链（浏览/diff/采用/乐观并发，WorkInspector）；④story md 快照自愈；⑤完全回滚（938–957 备份域闭环）；⑥R24 细粒度版本历史缓行中。
- **对标**：Scrivener Snapshots（基线+diff+逐段恢复，A1）；NovelCrafter 全域版本恢复已转正（B1，v4 对标源）；Obsidian 文件恢复（A6）。
- **判定**：**部分缺口**——回退式快照有、「章历史浏览+比较+定点恢复」的只读消费面无；v5 时挂「待反馈」，本轮复核 NovelCrafter 转正与本仓机制已备，只读半件门槛已到。
- **处置**：**R53**（章历史浏览+行级 diff+定点恢复 UI；恢复统一走既有恢复语义；标注「浏览只读」防误当正道）；写作中自动快照节奏（Scrivener 式会话快照）继续缓行待反馈。

## §7 一致性与知识域

- **现状**：实体卡 Codex 化场景感知注入（R10，source=`codex/<entity>`）；系列正典双层合并 book>series（R20）；三库资产（R4）+市场包（R15）；真相文件体系；伏笔状态机+类型+撤回（G10/R23）；信息差（G7）；反AI规则+种子包（R5/R22）；文风 compileStyleGuide（958 号对齐）。
- **对标**：NovelCrafter Codex tracking 控制（B1）；Sudowrite Story Bible 自动更新仍是社区请求（B2）；NovelAI Lorebook 关键词激活+图片嵌入分享（B3）；Pagekin 读者已知维度（B7）；蛙趣 8 类伏笔（C 类，v4 已吸收 R23）。
- **判定**：**领先或对齐**——注入链/生命周期/撤回语义/自动沉淀四点在 30 款内无完整等价物；排除短语治理（B1 2026-03）是唯一小增量。
- **处置**：排除短语挂 **R52 批次**；其余维持；R15 便携格式确认维持。

## §8 AI 编排与评测域

- **现状**：导演驾驶舱三模式（就绪即停/范围/全书=HITL 检查点）；best-of-N（G11）；场景节拍（R11）；行为评测+LLM-as-judge 15 用例四维（R8/R17）；任务路由 failover 链 retryCount≤5+backupModels≤3（R25/R399 接线）；章节目标防复读门（R28）。
- **对标**：LangGraph checkpointer/interrupt（D6 系）；DSPy GEPA 版本化+test-driven 部署（D7）；Dify Knowledge Pipeline 接入前先测（D6）；Sudowrite Scenes（B2）。
- **判定**：**对齐或领先**——HITL/接管链/评测面三点半径不劣于通用框架；缺的是 prompt 变更管理的「版本化纪律」（eval 已有、artifact 化无）。
- **处置**：**R54**（prompt pack 版本 artifact+变更触发 R8 回归门+回滚；GEPA 自动优化不采）；场景一等化挂 R57；「知识接入先测检索」语义并入 R54 流程纪律。

## §9 LLM 网关域

- **现状**：38 preset 分组+自定义服务（测试连接自动发现协议/流式/模型目录）；按任务路由（写作/审改/修复/检测/分析）；failover 链（R25）；RunLog 调用遥测（R26）；token 计量双源（R41）；thinkingBudget 备案。
- **对标**：LiteLLM virtual keys 双层预算+budget fallbacks（D1）；new-api 用量成本核算（D3）；OpenRouter 一次性模型（B1 一次性模型进 Chat）。
- **判定**：**对齐或领先**（单机 BYOK 形态下路由/failover/遥测三面全有）；缺「用量软顶警戒」——本地无计费语义，但共享 API 配额/包月额度是真实约束（CodingPlan 分组服务尤其如此）。
- **处置**：**R55**（per-service 软顶+接近告警+超额确认继续；纯本地语义无计费）；一次性模型**不采**（模型标签切换已等价）。

## §10 翻译域

- **现状**：翻译域 2.0 五期收官（契约补形/协议校验/审校 2.0/works 存储迁移/revise+create 三输入/epub 结构对齐/registered-sources 确认卡）；glossary 工件（`translation/project.rs` `merge_glossary_terms`）；修订 revise 面对照已有。
- **对标**：Immersive Translate 段落级双语对照+EPUB 翻译（F1）；BabelDOC 版式元数据与语义解耦（F2）；TM 翻译记忆（全类无一原生，immersive/babeldoc 术语层已有）。
- **判定**：**对齐 + 一个数据门控缺口**——双语对照「导出形态」（成稿 EPUB 交错阅读）与 TM 复用均等真实使用反馈。
- **处置**：双语对照导出挂观察清单（与 R56 同期评估）；**R56 TM 数据门控**；PDF 输入**不采**。

## §11 生态与扩展域

- **现状**：WASM 插件沙箱（fuel/内存/时限四层+权限逐项审批+注册表+自动禁用）；SKILL.md 兼容（AgentSkills/OpenClaw）+外部来源信任管理（768/769 号）；技能热刷新；`INKOS_SKILL_DIRS` 扩展点。
- **对标**：Open WebUI pipelines（D4，进程级隔离）；Obsidian 插件市场生态规模（A6）；anthropic skills 标准（简提）；LobeChat 技能市场（D5）。
- **判定**：**领先**——沙箱强隔离的桌面写作应用无第二例；插件生态规模是「先有钩子后有生态」的时序问题。
- **处置**：维持；MCP server 面（写作链暴露为 MCP 工具）挂**观察清单**（随上游 pi 生态定，避免提前押注协议形态）；技能目录结构演进跟随上游。

## §12 工程质量域

- **现状**：0GC/bench 门禁群（bench:gate 30 基准）；clippy:gate/fmt:gate -D warnings 双 crate；audit:rust 必红自检+audit:npm 形状卫兵；双栈差分器（契约/工具面/端点/SSE 四维）；生成式目录+verify 入 gate:ts（R40）；原子写 94 站；testgate/ignored-sweep 清单地板；编号工具化 next-change-no（R40.2）。
- **对标**：高星项目惯例（CI/覆盖门/发布自动化——Tauri/Dify/Langfuse 全有 CI）；Rust 社区 audit 惯例。
- **判定**：**领先（形态不同）**——无 CI 是既定裁定（fork-and-own+本地脚本发版），以「门禁脚本化+必红自检+编号工具」达成等价保障；30 款内无一家有双栈差分器与生成式目录纪律。
- **处置**：维持不变；门禁群为 R47–R55 新增面的既有验收基座（每项新增面挂 bench/golden/duel 相应闸）。
