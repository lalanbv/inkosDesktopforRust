# UI 体验优化功能规划与日程安排

- 日期:2026-08-23(周日)制定

## 度量与守护

- 每日:`pnpm -r test` 守绿;改动涉及 studio 时跑对应 vitest 子集;
- 每期:e2e(Playwright)+ `src-tauri cargo test` + 启动性能对照(dev 模式掐表 <600ms 首骨架);
- 常驻指标:命令面板覆盖率(路由 100%/动作 ≥30)、快捷键速查一致性(自动生成速查页与注册表比对)、骨架 CLS<0.02。

## 风险总表

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 导航重构引发路由回归 | 高 | feature flag+旧路径保留一版+纯函数映射单测 |
| macOS Overlay 标题栏事件穿透/遮挡 | 中 | 交互元素 stopPropagation;三平台条件配置 |
| 命令面板索引内容层性能(书多时) | 中 | 首版仅标题索引,全文检索二期;索引分页 |
| 单人节奏被临时插入打断 | 中 | 每期独立可发布,周任务按日粒度可顺延 |
| skeleton 与 SSE 增量渲染冲突 | 低 | 骨架仅覆盖首载,增量走既有 delta 通道 |
