## P1-1 骨架组件三件套(周一上午,0.5d)

**目标**:提供 行型/卡型/文本块型 骨架 + 延迟出现逻辑,后续所有页面统一使用。

**文件**:
- N `components/ui/skeleton.tsx` — 基础件(≈15 行,shadcn 标准):
  ```tsx
  // div + data-slot="skeleton" + className 合并 animate-pulse rounded-md bg-muted
  ```
- N `components/skeletons.tsx` — 三型组合件:
  ```ts
  export function SkeletonRows({ count = 5, className }: { count?: number; className?: string })   // 会话/章节列表行:图标圆 + 两行文本条
  export function SkeletonCards({ count = 3, className }: ...)                                     // 书架/仪表卡
  export function SkeletonParagraphs({ count = 4, ... }: ...)                                      // 正文段落(宽度错落:90%/100%/95%)
  export function useDelayedVisible(delayMs = 200): boolean                                        // setTimeout 翻转;卸载清理;<200ms 请求不闪骨架
  ```
- N `components/skeletons.test.tsx` — 渲染三型各一 + useDelayedVisible 假时钟测试(vi.useFakeTimers)。

**步骤**:① 写 skeleton 基础件;② 写三型组合与 hook;③ 测试;④ 在 `index.css` 无需新增(pulse 内置)。
**验收**:vitest 绿;三型在浅/深主题下 muted 色可辨(目测)。

## P1-5 命令面板 MVP(周三全天,1d)

**目标**:Cmd+K 唤起,索引**导航层**(全部页面)+ **最近访问**;空查询显示最近+推荐。

**文件**:
- N `lib/commands.ts` — 命令模型与注册表(**核心纯函数,全部可测**):
  ```ts
  export interface CommandEntry {
    id: string;                       // "nav.dashboard" / "action.theme.toggle" / "recent.xxx"
    group: "navigation" | "action" | "recent";
    titleZh: string; titleEn: string; // 过滤与展示双语
    keywords?: string[];              // 拼音/别名可后补
    hotkey?: string;                  // 展示用("⌘B"),P2 注册表复用
    icon?: string;                    // lucide 名,渲染层映射
    run: (ctx: CommandContext) => void;
  }
  export interface CommandContext { nav: App["nav"] 类型; setTheme: ...; refetchProject: ...; }
  export function buildNavigationCommands(ctx): CommandEntry[]   // 由 23 种路由去重出页面级 ≈20 条
  export function filterCommands(list: CommandEntry[], query: string, lang: "zh"|"en"): CommandEntry[]
  // 过滤规则:title/keywords 不区分大小写 includes;query 空 → 原样(group recent 优先)
  export function groupCommands(list): Array<{ group; entries }>  // 分组排序:recent < navigation < action
  ```
- N `store/recents/`(store.ts/types.ts/index.ts + store.test.ts)— 照抄 preferences 模式:`pushRecent(route: { page; label; params })` 保最近 8 条,localStorage key `inkos:studio:recents`;
- N `components/CommandPalette.tsx` — 组合 `ui/command` 的 `CommandDialog`:
  - 空查询:最近访问组 + 推荐动作(新建小说/继续上次/打开设置)前 3;
  - 输入过滤:`filterCommands`;分组渲染;条目右侧显示 hotkey 徽标;
  - 空结果:显示「没有匹配的命令」+ 引导动作「创建新书」(不死胡同);
  - Esc 关闭(cmdk 内建);`↑↓↵` 内建。
- M `App.tsx` — 挂载 `<CommandPalette ctx={...}/>` + 临时 keydown(Cmd/Ctrl+K,P2 迁入统一 hook);nav 调用后 `pushRecent`。

**测试**:`commands.test.ts`(构建/过滤/分组,含中英文 query 与空串)+ `recents/store.test.ts`(去重、上限 8、持久化)+ CommandPalette 渲染冒烟。
**验收**:Cmd+K 可达全部页面路由(对照 parseHash 23 变体的页面级去重清单);最近访问在切换页面后更新。
