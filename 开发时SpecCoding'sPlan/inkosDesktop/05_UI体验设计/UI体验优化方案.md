# inkosDesktop UI 体验优化方案

- 日期:2026-08-23
- 依据:《参考案例对比分析.md》十二条设计原则
- 范围:packages/studio(Studio 工作台)+ src-tauri(桌面壳)
- 原则总纲:**不动视觉根基(双主题/字体/文学气质是资产),补交互层与桌面融合层**

---

## 二、八大优化项详设

### 1. 全局命令面板(Cmd+K)——优先级最高

- **实现基础**:cmdk 已在依赖,`ui/command.tsx` 已存在,补全局挂载与索引。
- **索引四层**(参照 JetBrains Search Everywhere + VSCode 前缀语法):
  1. 页面/导航(20+ 路由直达);
  2. 动作(新建书/切主题/切语言/开始生成/导出…);
  3. 内容(书名/章节标题/会话标题,后续二期加全文);
  4. 设置项(跳转到 ProjectSettings 对应锚点)。
- **交互细则**:空查询时列出「最近访问 + 推荐动作」(Raycast 教训:首屏必须有结果);输入即模糊匹配;分组显示快捷键提示;`Esc` 关闭、`↑↓` 选择、`↵` 执行;空结果给出「创建新书」引导而非死胡同。
- **入口**:顶栏搜索框(点击即开)+ `Cmd+K`;后续 `Cmd+P` 限定"内容层"快速打开。

### 2. 导航重组——活动栏 + 分组侧边栏

- **活动栏(48px,左侧)**四个心智区(icons:PenLine 铁笔/Wrench 扳手/Settings2 管理/Clapperboard 影视)+ 底部固定(设置/主题/账号):
  1. **创作**:我的书(会话树)、最近、收藏;
  2. **工具**:题材、风格、翻译、导入、雷达、真相文件;
  3. **管理**:服务、守护进程、日志、医生、项目设置;
  4. **互动影视**:影视项目列表、FilmWizard。
- **侧边栏**:宽度可拖(180~400px,记忆)+ 过滤框(DBeaver 树过滤范式,书目/会话多时刚需)+ `Cmd+B` 折叠为纯图标条 + 空态引导。
- **顶栏 widget 化**(JetBrains New UI 范式):面包屑(书/章节,可点返回)+ 命令面板入口 + AI 模型/服务常驻切换器(Insomnia 环境切换器范式)+ SSE 同步指示(保存态低调呈现,Figma 范式)+ 语言/主题(保留现状)。
- **过渡策略**:活动栏默认展开、首次启动给一次性导览气泡(渐进披露,不吓老用户)。

### 3. 加载三级体系(替换全屏 spinner)

| 层级 | 场景 | 方案 |
| --- | --- | --- |
| 窗口级 | App 启动 gate | 先渲染应用骨架(顶栏+侧栏+空主区,InkosLogo 呼吸动效),配置就绪后渐进填充;**绝不白屏等 spinner**;语言选择器做成居中 Dialog 而非整屏替换 |
| 区域级 | 列表/卡片/正文 | 新建 `ui/skeleton.tsx` 三型:行型(会话/章节列表)、卡型(Dashboard/书架)、文本块型(章节正文段落);`animate-pulse`,200~400ms 延迟出现(避免闪烁) |
| 控件级 | 按钮/行内 | 统一用 `ui/spinner.tsx`(尺寸 sm/md,按钮内嵌);发送/生成中的按钮显示 spinner+可取消 |
| 任务级 | 生成/导入/扫描 | 底部"面板"流式呈现(类 JetBrains Run 面板)+ 状态栏指示 + 通知中心汇总(INFO/WARN/ERROR 分级,非阻塞);后台任务可查看进度、可取消(对齐 VSCode v1.110 AI 任务可控可见) |

- **E2E 契约**:加载态统一 `data-loading="shell|skeleton|control"` 便于测试与走查。

### 4. 快捷键体系(从零到全家桶)

| 键 | 动作 | 参照 |
| --- | --- | --- |
| Cmd+K | 命令面板 | Linear/VSCode |
| Cmd+P | 快速打开(书/章节/会话) | VSCode |
| Cmd+B | 侧边栏折叠 | VSCode/Obsidian |
| Cmd+J | 底部面板开合 | VSCode |
| Cmd+E | 最近访问弹出 | JetBrains |
| Cmd+1..9 | 切换主区标签页 | Figma/VSCode |
| Cmd+Shift+F | 全局搜索(内容层) | VSCode |
| Cmd+Enter | 发送(输入区) | 通行 |
| Esc | 停止生成/关闭面板 | 通行 |
| Cmd+/ 或 ? | 快捷键速查弹层 | Slack/GitHub |

- 实现:统一 `hooks/use-global-hotkeys.ts`(keydown 单点分发,输入框聚焦时自动放行文本键);**所有快捷键同时注册为命令面板条目**(可发现性兜底)。

### 5. 多任务:标签页 + 最近访问

- 主内容区标签化:书/会话/章节/设定页以标签共存;标签可关闭、可 pin、溢出滚动;`Cmd+W` 关当前;
- 预览语义:单击=预览(重用标签),双击=驻留(VSCode preview tab 范式,防标签爆炸);
- 恢复:记住上次标签集与会话(hash 路由已支持深链,补持久化到 localStorage);
- 上下文面板(BookSidebar)泛化为右侧 dock:宽度记忆、`Cmd+Shift+D` 开合,随活动区自动切换内容(设定集/大纲/进度/工具执行)。

### 6. 阅读与写作体验(核心场景做深)

- **ChapterReader 排版**:正文度量行宽 38~42em 中文(约 720~840px)、行高 1.9~2.0、段间距=1.5 字高;正文/界面字体分离已具备(Instrument Serif),补字号三档(15/17/19px)与背景纸感选项(纯色/纸纹);
- **沉浸阅读**:隐藏顶栏与活动栏(自动隐藏式,鼠标到顶唤回)+ 阅读进度条(细条置顶)+ 章节导航(左右键翻章);
- **专注写作**(Zettlr 打字机模式):当前句/段高亮、其余降不透明度;可开关;`prefers-reduced-motion` 时禁用平滑滚动;
- **Focus Mode 全局模式**(2026 趋势):一键进入=低对比主题变体+隐藏非必要面板+去动效+通知静默,状态栏常亮提示,Esc 退出;
- **写作统计置底**:状态栏实时字数/预计阅读时长(Obsidian 范式)。

### 7. 桌面原生融合(src-tauri)

- **macOS 融合标题栏**:`tauri.conf.json` 窗口加 `"titleBarStyle": "Overlay"` + `"hiddenTitle": true`,Web 顶栏 padding-left 预留 78px 交通灯位并整条设 `data-tauri-drag-region`(交互控件内层元素阻止拖拽冒泡);Windows/Linux 保留系统标题栏(避免跨平台陷阱);
- **窗口状态记忆**:尺寸/位置/最大化状态持久化(tauri-plugin-window-state 或自实现 config 落盘),启动恢复;
- **启动体验**:窗口先显示再加载内容(配合骨架体系),`visible: false` + 就绪 `show()` 防白闪,或直接热启动(优先,配合渐进渲染);
- **深浅主题跟随系统**:`useTheme` 增加 "auto" 档监听 `prefers-color-scheme`;
- **菜单栏(macOS)**:基础菜单(新建/打开/编辑/视图/窗口)+ 快捷键声明,使系统快捷键与 Web 端一致;
- 已有托盘保留,补充"生成中"托盘角标指示。

### 8. 反馈体系:空态/错误/通知/动效

- **空态规范**:每列表页统一 `EmptyState` 组件(插画位+一句引导+主行动按钮,如「书架空空——创建第一本书」);
- **错误分级**:可重试错误=inline + 重试按钮(现有 startupGate 模式推广到各页);不可恢复=Dialog;后台异常=通知中心;
- **通知中心**:右下角铃铛汇总(1Password/Slack 范式),不阻塞、可清空;
- **动效规范**:token 化 `--motion-fast: 150ms / --motion-base: 200ms / --motion-slow: 250ms`;仅透明度/位移/缩放单属性;全局尊重 `prefers-reduced-motion`;
- **密度档位**:舒适(默认)/紧凑两档(紧凑:行高与内边距 ×0.85,列表类页面收益最大),存 preferences store(已有 store/preferences 目录)。

## 三、主题与视觉策略(守正)

- **保留**:暖羊皮纸/黑曜石双主题、Instrument Serif+DM Sans+JetBrains Mono 三字体分工、oklch 变量体系——这些是差异化资产;
- **新增**:① Focus 模式低对比变体(仅调整 --muted/--border/--background 三变量即可派生);② 阅读纸纹背景(可选,CSS 渐变实现,默认关);
- **统一 radius/shadow 现状**已达标(--radius 0.6rem + shadow-soft/3d),不追圆角潮流(VSCode 争议教训),但用密度档位给专业用户选择权;
- **图标**:lucide 统一 16px(侧栏/按钮)/18px(顶栏),stroke 1.5。

## 四、不做清单(防 scope 失控)

- 不引入组件库大换血(现有 shadcn/Base UI 足够);
- 不做自定义皮肤市场/多主题自定义器(投入产出比低);
- 不做 Windows Mica 特效定制(等 P4 后按需评估);
- 不动后端 API 与 SSE 契约(纯前端+壳层改动,`__tests__` 契约测试全保)。

## 五、验收口径

- 功能验收:命令面板覆盖 100% 页面路由与 ≥30 个动作;快捷键速查页与实现一一对应;
- 性能验收:启动到首屏骨架 <600ms(本地 dev 对照),骨架→内容无布局跳动(CLS<0.02);
- 回归:`pnpm -r test` 全绿 + studio e2e(Playwright)全绿 + src-tauri `cargo test` 全绿;
- 走查:十大维度对照《参考案例对比分析.md》矩阵复评,目标均值 ≥4.0。
