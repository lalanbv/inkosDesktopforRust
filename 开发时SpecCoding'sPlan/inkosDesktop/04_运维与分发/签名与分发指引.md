# 签名与分发指引（inkosDesktop）

> macOS / Windows / Linux 三平台可分发性 + shell updater 签名 + 用户安装指引。
> 签名**逻辑**（ad-hoc 默认 + CI secrets gating）在 `.github/workflows/desktop-build.yml`；
> 本文档是**运维设置**（secrets 配置）+ **用户分发**指引。
> 对应 M3 总体设计 §4 M3f + §8 安全。

## 1. 当前签名策略（GitHub OSS，无 Apple Developer ID）

本项目是 GitHub 开源，任何人可下载安装。**无 Apple Developer ID**，故：

| 平台 | 签名 | 用户首次运行 |
|---|---|---|
| macOS | **ad-hoc**（`codesign --force --sign -`，二进制自洽） | Gatekeeper 拦「未识别开发者」→ 用户 `xattr -dr`（见 §3） |
| Windows | 无 Authenticode（可选 EV 证书 Phase 2 评估） | SmartScreen 拦「未识别应用」→ 用户「仍要运行」 |
| Linux | 无签名（AppImage 无需） | `chmod +x` 即可 |

**未来升级路径（CI secrets gating，零代码改动）**：在 GitHub Settings → Secrets 配齐
`APPLE_*` / Authenticode 私钥后，`desktop-build.yml` 的 tauri-action 自动升级为
Developer ID 签名 + notarization（macOS）/ Authenticode（Windows），用户免手动放行。
未配 secrets 时自动回退 ad-hoc/无签名。

## 2. CI Secrets 配置（运维）

GitHub 仓库 Settings → Secrets and variables → Actions → New repository secret：

### 2.1 shell updater（Ed25519）—— 必配（否则 shell 自更新不可用）

```
TAURI_SIGNING_PRIVATE_KEY          = <私钥全文>（scripts/desktop-gen-updater-key.sh 生成）
TAURI_SIGNING_PRIVATE_KEY_PASSWORD = <密码>（生成时设的密码；空则不配）
```

对应公钥已嵌入 `src-tauri/tauri.conf.json` `plugins.updater.pubkey`。
**生产前建议重新生成自控 keypair**（私钥仅维护者持有）：

```bash
./scripts/desktop-gen-updater-key.sh /tmp/my-key
# 按输出把公钥贴进 tauri.conf.json，私钥设为 CI secret
```

### 2.2 macOS Developer ID 签名 + 公证（可选，未来配）

```
APPLE_CERTIFICATE          = <.p12 base64>（Developer ID Application 证书导出）
APPLE_CERTIFICATE_PASSWORD = <.p12 导出密码>
APPLE_ID                   = <Apple ID 邮箱>
APPLE_PASSWORD             = <app-specific password>（appleid.apple.com 生成）
APPLE_TEAM_ID              = <Team ID>
```

齐配后 tauri-action 自动签名 + `notarytool` 公证 + stapler。

### 2.3 Windows Authenticode（可选，未来配）

```
TAURI_SIGNING_PRIVATE_KEY     = <pfx base64>
TAURI_SIGNING_PRIVATE_KEY_PASSWORD = <pfx 密码>
```

## 3. 用户安装指引（发版 notes 引用）

### macOS（无 Developer ID / ad-hoc 签名）

首次打开会被 Gatekeeper 拦截「无法验证开发者」。两种放行方式：

```bash
# 方式 A：命令行去隔离（推荐，一次到位）
xattr -dr com.apple.quarantine /Applications/inkosDesktop.app

# 方式 B：GUI 右键打开 → 「仍要打开」（每次版本更新可能重复）
```

> Apple Developer ID 签名配置后（§2.2），用户免此步。

### Windows

首次运行 SmartScreen 拦「已保护你的电脑」→ 点「更多信息」→「仍要运行」。
Authenticode 签名（§2.3）后免此步。

### Linux（AppImage）

```bash
chmod +x inkosDesktop_*.AppImage
./inkosDesktop_*.AppImage
```

（也可用 AppImageLauncher 集成桌面。）

## 4. 发版清单（release checklist）

发版前维护者确认：

- [ ] upstream 已同步（`desktop-sync-regression` 最近一次 green）
- [ ] `pnpm test` + `cd src-tauri && cargo test && cargo clippy --all-targets -- -D warnings` 全绿
- [ ] `packages/cli/package.json` version 与 `src-tauri/Cargo.toml` version 与 `src-tauri/tauri.conf.json` version 三处一致且 = tag 版本
- [ ] shell updater keypair：tauri.conf.json pubkey ↔ CI secret TAURI_SIGNING_PRIVATE_KEY 配对（§2.1）
- [ ] 打 tag：`git tag -a v0.3.0-m3 -m "..."` → push → `desktop-build.yml` 自动发版（4 平台 + latest.json + engine bundle）
- [ ] release notes 附 §3 用户安装指引（macOS xattr / Windows SmartScreen / Linux chmod）

## 5. 安全说明

- 所有 secrets 仅在 CI（不在仓）；Ed25519 / Apple / Authenticode 私钥均 CI 侧。
- engine 通道 updater：SHA256 强校验（.sha256 asset）。
- shell 通道 updater：Ed25519 验签（latest.json 签名 + pubkey 嵌二进制校验）。
- 无静默自动安装：用户经 `cmd_apply_*` 主动触发；更新下载到 staging，校验通过才替换。

## 6. ad-hoc 签名本地验证（dev）

```bash
cd src-tauri && cargo tauri build
# 产物：target/release/bundle/...
codesign -dv target/release/bundle/macos/inkosDesktop.app  # macOS：应见 ad-hoc (Identifier)
```
