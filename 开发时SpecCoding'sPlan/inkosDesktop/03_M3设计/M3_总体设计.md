## 1. 用户授权与关键约束（三项决策定稿）

| # | 决策 | 定稿（用户指令） |
|---|---|---|
| Node 打包 | **运行时自适应 bootstrap**（非构建期打包） | 按用户平台/arch/地区自行下载最佳 Node：region-aware mirror（官方 nodejs.org + 中国 npmmirror 等）+ SHA256 校验 + 本地缓存。产物小、全球用户各取最佳镜像、可扩展 mirror 列表 |
| macOS 签名 | **ad-hoc + CI gating + OSS 指引** | 无 Apple Developer ID；ad-hoc 签名（`codesign -s -`）保二进制自洽；CI pipeline 在 `APPLE_*` secrets 存在时自动升级为 Developer ID 签名+公证（未来即用）；README/release notes 给 `xattr -dr com.apple.quarantine` 指引 |
| updater 范围 | **双通道自更新**（engine + shell） | engine 通道：GitHub Releases `v{semver}` → SHA256 → 原子替换 + 回滚；shell 通道：Tauri updater + Ed25519 签名；都更新到当前 GitHub 最新版本 |

> 上游 tag 格式已消解（架构 §14.1）：`v<MAJOR>.<MINOR>.<PATCH>`（v0.4.6→…→v1.7.2）。updater 用 GitHub Releases API 探测 latest `v{semver}`。

## 2. 子里程碑分解（线性依赖链）

```
M3a engine 资源化 + 解 C1 + paths/config cleanup
  └─→ M3b 项目选择窗口 + 解 C2（提供 pre-sidecar 原生窗口基础设施）
        └─→ M3c 运行时 Node 自适应 bootstrap（region-aware，用 M3b 窗口显进度）
              └─→ M3d 双通道 updater（engine + shell，用 M3b 窗口显进度）
                    └─→ M3e CI（三平台构建 + 同步回归 + SSE 契约）
                          └─→ M3f 签名 + OSS 分发指引
```

每个子里程碑独立 spec→plan→TDD→commit→变更记录，保持上下文聚焦、可独立验收。

## 3. 跨里程碑共享基础设施

### 3.1 app_data 目录布局（paths 扩展）

```
{app_data}/inkosDesktop/           # dirs::data_dir()（每平台 OS 标准位置）
├── projects.json                  # M3b：最近项目列表 + last_opened
├── logs/                          # M3e：tracing 日志（架构 minor M4）
├── runtime/
│   └── node/{ver}-{plat}-{arch}/  # M3c：bootstrap 下载的便携 node（SHA256 已校验）
├── engine/                        # M3a：从 Tauri resource 解压/指向的 inkos dist（当前版本）
│   ├── dist/（cli/core/studio dist + SPA 静态 + genres/skills/提示词）
│   └── manifest.json              # 版本 + SHA256 + node 最低版本
├── engine.bak/                    # M3d：updater 回滚备份
└── updates/staging/               # M3d：updater 下载暂存
```

### 3.2 pre-sidecar 原生窗口（M3b 建一次，M3c/M3d 复用）

Tauri 主窗口在 sidecar 起来**之前**先加载一个极小本地 HTML（`tauri://`/`asset:` 协议，非 sidecar URL），承担：
- **M3b**：项目选择（最近列表 + 原生目录选择对话框）
- **M3c**：首启 Node bootstrap 进度（进度条 + 镜像源 + 阶段）
- **M3d**：更新检查/应用进度

窗口通过 Tauri command + event 与 Rust 双向通信（`__inkosDesktop__.setProgress`/`pickProject`/`checkForUpdates`）。选定项目 + node 就绪后，导航主窗口到 `http://127.0.0.1:<port>/`。

> 此窗口**不依赖 SPA/sidecar**，解决 C2 的鸡生蛋问题（选项目需在 sidecar 前）。

### 3.3 共享 HTTP 客户端

M3c（node 下载）与 M3d（updater 下载）共用一个 `reqwest::Client`（连接池/TLS 复用，对齐 M2a C8 优化）。封装为 `HttpClient`（带超时 + 重试 + 进度回调）。

### 3.4 manifest.json schema（M3a 定，M3c/M3d 用）

```jsonc
{
  "engine_version": "1.7.2",        // 对齐 inkos package.json version
  "engine_sha256": "<hex>",          // engine/dist 整体 tarball 的 SHA256
  "node_min": "22.0.0",              // bootstrap 最低 node 版本
  "built_at": "2026-08-06T..."       // 打包时间（审计用）
}
```

### 3.5 config 集中化（架构 minor M5）

`config.rs` 收口所有常量：端口、超时、URL（node 镜像、GitHub API、updater manifest）、env 名、路径相对名、版本号。零硬编码散落。

## 4. 各子里程碑设计摘要

### M3a — engine 资源化 + 解 C1 + cleanup

- **目标**：打包后二进制能找到 inkos dist（不再依赖编译期 `CARGO_MANIFEST_DIR`）。
- **手段**：
  - `scripts/desktop-package-engine.sh`：仓库根 `pnpm build` → 组装 `engine/dist/`（cli/core/studio dist + SPA 静态 + genres/skills/提示词）→ 算 SHA256 → 写 `engine/manifest.json`。
  - `tauri.conf.json`：`bundle.resources` 含 `engine/`（随包分发）。
  - `paths.rs`：加 `engine_dir()`（= Tauri `resource_dir()/engine`）、`runtime_dir()`、`projects_path()`、`updates_staging_dir()`；**`submodule_root`→`repo_root` 重命名**（审计 minor）。
  - `main.rs`：`resource_dir()` 解析 engine，替换 `CARGO_MANIFEST_DIR`（**解 C1**）；`build_launch` 的 `cli_entry` 取自 `engine/dist/cli/index.js`；node 暂仍系统 `node`（M3c 接 bootstrap）。
- **测试**：manifest schema 单测；resource 路径解析（mock PathResolver）；`#[ignore]` 真实打包冒烟。

### M3b — 项目选择窗口 + 解 C2

- **目标**：首启/多项目时让用户选项目目录；持久化最近项目。
- **手段**：
  - 极小 HTML（`src-tauri/picker/index.html`，原生 `asset:` 协议加载）+ Tauri command：`list_recent_projects`/`pick_project_dialog`/`choose_project`。
  - `projects.json` 读写（0600 原子写，复用 M2b `atomic_write` 模式）：`{ recent: [{path, name, last_opened}], last_opened }`。
  - `main.rs` 启动流：读 projects.json → 仅 1 个 recent 且配置 auto → 直接用；否则显 picker 窗口 → 用户选 → 持久化 → 进入 sidecar 启动（**解 C2**，移除 temp 占位）。
- **测试**：projects.json round-trip + schema；最近项目排序/去重；picker command 契约（mock）。

### M3c — 运行时 Node 自适应 bootstrap（region-aware）

- **目标**：app 首启按用户平台/地区下载最佳 Node，缓存复用；不依赖系统 node。
- **手段**：
  - `NodeResolver` trait：`resolve() -> NodeBin`（`BootstrappingResolver` 生产 / `SystemFallbackResolver` 兜底）。
  - `MirrorSelector` trait：按地区/延迟选镜像。`LocaleMirrorSelector`：检测 `LANG`/`LC_ALL`/时区含 `zh`/`CN`/`Asia/Shanghai` → 优先 npmmirror，否则 nodejs.org；可配 override；**并行竞速**或**有序回退**（首镜失败自动切官方）。
  - 下载：node 官方 `SHASUMS256.txt`（HTTPS pinned 官方源）做权威校验——即使二进制取自 mirror，也用官方 checksum 验证（mirror 无法伪造）。解压到 `runtime/node/{ver}-{plat}-{arch}/`。
  - 进度：复用 M3b picker 窗口（`setProgress` event）。
  - `build_launch`：node_bin = bootstrap 缓存路径（首启异步 bootstrap，已缓存则同步命中）。
- **安全**：SHA256 强校验；HTTPS；失败回退系统 node（降级 log，不阻塞）。
- **测试**：MirrorSelector 地区判定（locale/时区矩阵）；SHA256 校验（tampered blob 拒绝）；解析缓存命中/未命中；`#[ignore]` 真实下载冒烟。

### M3d — 双通道 updater（engine + shell）

- **目标**：主动检查并更新到 GitHub 最新版本；engine 原子替换+回滚，shell Ed25519 签名自更新。
- **手段**：
  - `UpdateChannel` trait：`latest() -> ReleaseInfo` / `download() -> StagedArtifact`。`EngineChannel`（GitHub Releases engine tarball）/ `ShellChannel`（Tauri updater）。
  - **engine 通道**：查 `https://api.github.com/repos/<本仓 owner/name>/releases/latest`（**始终本 fork**，非直接拉 Narcooo/inkos）→ 比对 `engine_version` → 下载到 `updates/staging/` → SHA256（manifest 内嵌）→ 备份 `engine/`→`engine.bak/` → 原子替换（POSIX `rename` / Win `MoveFileEx(MOVEFILE_REPLACE_EXISTING)`）→ 健康预检（用已 bootstrap 的 node + 新 engine dist 跑 `inkos doctor` 可选）→ 失败回滚 `engine.bak`。
  - **上游同步链路（澄清）**：engine 更新**不直接**拉 upstream；而是 M3e `desktop-sync-regression.yml` CI 定时 `git merge upstream/master` → bump 版本 → 打 tag → `desktop-build.yml` CI 构建并发布 engine bundle 到**本仓** GitHub Releases → 本机 updater 拉本仓 release。如此「跟随上游」以「CI 同步 + 本仓发布」兑现，单一可信源（本仓 release），审计清晰。
  - **shell 通道**：Tauri 2 `tauri-plugin-updater` + Ed25519（`TAURI_PRIVATE_KEY` CI secret，公钥嵌 `tauri.conf.json` `updater.pubkey`）；更新到本仓 GitHub latest release。
  - Tauri command：`check_updates`/`apply_engine_update`/`apply_shell_update`；picker 窗口显进度。
  - 触发：启动后台检查（notify 不强装）+ 手动「检查更新」+ 定时（默认 24h）。
- **测试**：版本比较（semver）；SHA256 校验；原子替换 + 回滚（fake engine dir temp）；staging 清理；`#[ignore]` 真实 release 探测。

### M3e — CI（三平台 + 同步回归 + SSE 契约）

- **目标**：自动化三平台构建 + 上游同步回归 + SSE 契约测。
- **手段**（**新增** `.github/workflows/desktop-*.yml`，零交叉不碰 inkos `ci.yml`/`release.yml`）：
  - `desktop-build.yml`：matrix `[macos-latest, ubuntu-latest, windows-latest]` × `[x64, arm64]`（按平台支持裁剪）→ pnpm build → `desktop-package-engine.sh` → `cargo tauri build` → 签名（gated）→ 上传产物；tag 触发时生成 updater manifest（`latest.json` + Ed25519 签名）+ 创建 release。
  - `desktop-sync-regression.yml`：schedule（每日）+ workflow_dispatch → `git fetch upstream && git merge upstream/master` → `pnpm build` → `inkos doctor` + 写一章冒烟 + SSE 契约测（`sse_contract.rs`）→ 冲突/失败开 issue。
  - SSE 契约测纳入 desktop CI（已存 `tests/sse_contract.rs`）。
- **测试**：CI 自身（首次 push 验证 green）。

### M3f — 签名 + OSS 分发指引

- **目标**：无 Apple Developer ID 下的最佳可分发性 + 未来就绪。
- **手段**：
  - **macOS**：ad-hoc 签名（`codesign --force --sign - <app>`）保二进制自洽；CI 在 `APPLE_CERTIFICATE`+`APPLE_ID`+`APPLE_PASSWORD`+`APPLE_TEAM_ID` secrets 齐备时自动升级 Developer ID 签名 + notarytool 公证（未来即用，零代码改动）。
  - **Windows**：`TAURI_SIGNING_PRIVATE_KEY`（Authenticode，可选）gated；无则 SmartScreen 指引。
  - **指引文档**：README/release notes 给 macOS 用户 `xattr -dr com.apple.quarantine /Applications/inkosDesktop.app`（标准 OSS 做法）；Windows SmartScreen 「仍要运行」；Linux AppImage `chmod +x`。
- **测试**：ad-hoc 签名产物 `codesign -dv` 验证；CI gated 分支 dry-run。

## 5. 安全设计（贯穿）

| 层 | 措施 |
|---|---|
| 下载校验 | Node 二进制用官方 `SHASUMS256.txt`（HTTPS pinned）校验，mirror 无法伪造；engine bundle 用 manifest 内嵌 SHA256 |
| 签名 | shell 更新 Ed25519 签名验证（公钥嵌二进制）；engine 更新 SHA256 + release 来源 GitHub（HTTPS）|
| 原子性 | engine 替换用目录 rename（POSIX 原子）/ Win MoveFileEx；保留 engine.bak 回滚 |
| 权限 | runtime/ engine/ projects.json 均 0700/0600（复用 M2b 原子写模式）|
| 降级 | bootstrap 失败回退系统 node（log 不阻塞）；updater 失败回滚 + 通知；签名失败 ad-hoc 兜底 |
| 无静默 | 所有 fallible 路径显式 log + UI 提示 |

## 6. 性能 / 0GC 定位（诚实）

- Rust 壳先天 0GC（稳态接近零堆分配）；M3 新增路径（bootstrap/updater）均为**低频**（首启/更新），非热路径，分配可接受。
- 共享 `reqwest::Client`（连接池/TLS 复用，对齐 C8）。
- HTTP 下载流式（`stream` feature，已在 Cargo.toml），避免大 blob 一次性入内存。
- 镜像**并行竞速**或**首镜优先 + 官方回退**：地区最优延迟，失败不卡。
- inkos 侧（V8 GC）非性能瓶颈（架构 §9.1 已证）；node bootstrap 一次性，常驻后零开销。
