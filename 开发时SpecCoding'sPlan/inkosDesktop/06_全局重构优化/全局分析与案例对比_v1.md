- **结论：迁移主体已完成，进入"巩固+优化"阶段，重心从功能搬运转向安全/性能/扩展质量。**

### 1.4 已核验的短板清单（按风险排序）

| # | 短板 | 证据 | 风险级别 |

## 3. 对比结论

### 3.1 本项目的独特定位（交叉对比后）

30 案例中**无一同时具备**：本地优先文件真源 + Rust 引擎 + 多 LLM BYOK + 长篇治理（hooks/state/forecast）+ 桌面级沙箱插件。最接近的拼图是：Novelcrafter（BYOK+Codex）+ Scrivener（Binder）+ SillyTavern（play 面）+ Zed（Rust 性能文化）的组合体。**竞争坐标应锚定"可治理的本地 AI 长文工作站"**，而非通用笔记或纯 chat。

### 3.2 优势（保持项）

1. 契约测试文化（duel/golden）在同类开源项目中罕见；
2. Rust 引擎直启已完成主体迁移，双端 2000+ 测试全绿；
3. 安全基建（keyring/原子写/Ed25519/路径防护/wasmtime 沙箱）领先多数同类；
4. 注释与边界文档化（TOCTOU、AppleDouble、进程组语义）是长期资产。

### 3.3 差距（修复项 → 映射到总体方案）

| 差距 | 对标来源 | 方案条目 |
|------|----------|----------|
| 本地服务无信任边界（S1/S2） | Jupyter #21、VS Code #19/#22 | W-A1 回环守卫（本轮） |
| 静态面缺安全头（S5） | 所有 Web 面产品标配 | W-A3（本轮） |
| SSE 逐订阅者克隆（S7，实施期复核为零收益改判）+ 静态面每请求整页拷贝 | Zed 零拷贝文化 #17 | W-B1 修正版（本轮） |
| 优雅停机缺失（S6） | 常规服务化标准 | W-B2（backlog） |
| 系列书导入回填向导 | Sudowrite #1 | W-C3（backlog，产品级） |
| 故事时间线可视化 | Plottr #10 | W-C4（backlog，产品级） |
| 检查点恢复语义显式化 | LangGraph #23 | W-C5（backlog） |
| serde_yaml 技术债（S4） | — | W-C6（评估替换） |
| 文档漂移/plan 散置（S8） | — | W-D2（本轮顺带） |

### 3.4 0GC/性能的诚实结论（承接 02 号 roadmap）

1. **已证伪勿再做**：WASM Store 池化（wasmtime 实例计数崩溃）、serde JSON 栈缓冲（实测 +11% 回退）；
2. **已到位**：Linker/Component/Engine 复用、HTTP 流式预分配、正则 OnceLock；
3. **真热点在低频大对象**：LLM 流（网络主导）、章节全文 JSON 序列化（每请求一次，非每 token）——微优化收益 < 稳定性收益；
4. **本轮唯一值得做的分配优化**：SSE payload Arc 化（消逐订阅者整串拷贝，零风险）；
5. **性能工作的正确形态**：bench 常态化门禁（本地脚本，无 CI——149 号已定）+ 每次优化必须有 profiler/基准前置。
