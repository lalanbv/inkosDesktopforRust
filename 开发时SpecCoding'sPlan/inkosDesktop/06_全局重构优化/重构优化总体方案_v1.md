## 1. 目标与非目标

### 1.1 目标（按用户要求五维展开）

| 维度 | 目标 | 验收标准 |
|------|------|----------|
| 最优解 | 修复已证实的 S1/S2（secrets 跨源可读），方案取业界最小代价路径（Origin/Host 回环校验，非重型 token） | 恶意 Origin/Host 请求 403，全部既有客户端零改动 |
| 最佳兼容性 | 契约面（107 端点、duel 8/8、golden 向量）零破坏；webview/健康探测/curl/duel/Vite dev 五类客户端回归全绿 | 双端测试套件 EXIT:0 |
| 最佳可扩展性 | 守卫做成可组合 middleware 并留 env 扩展点；SSE payload 结构变更不对外泄漏 | 新增单测覆盖扩展点 |
| 安全可靠 | 回环守卫默认开启 + 可关回滚；静态面补安全头；Node 回退侧同步（保持双端安全水位一致） | 新增安全单测全过 |
| 高性能 0GC | 只做已验证方向的优化：SSE payload Arc 化（消逐订阅者整串拷贝）；**明确拒绝** 02 号已证伪项 | 现有 SSE 测试语义不变 + 新增 Arc 语义测试 |

### 1.2 非目标（明确不做）

1. 不做 WASM Store 池化、serde 栈缓冲优化（02 号实测证伪：崩溃 / +11% 回退）；
2. 不引入 token 鉴权体系（Origin/Host 校验已覆盖浏览器攻击面；本地进程本可读 secrets.json，token 无增量收益，却引入 UI 传递难题）；
3. 不做 CRDT/协编辑（30 案例对比结论：选配非默认，文件真源+版本归档已够）；
4. 不动 107 端点契约与 CORS parity（Hono 对齐是 duel 锁定的既定事实，收紧 CORS 需 Node 侧同步，列入 backlog 而非本轮）；
5. 不写任何 GitHub Actions/workflows（149 号决定，全部本地脚本）。

## 2. 设计原则

1. **契约先行**：任何引擎侧变更先确认 duel/golden 语义不变；新增行为必须有对称测试。
2. **profiler/证据先于假设**（02 号血泪教训）：每条优化注明证据来源（bench/代码事实）。
3. **默认安全 + 单一开关回滚**：守卫默认开启，`INKOS_ENGINE_LOOPBACK_GUARD=0` 一键回到旧行为。
4. **双端同水位**：Rust 默认链路与 Node 回退链路的安全行为保持一致（回退不降级安全）。
5. **增量绞杀**：不做大爆炸重构；每项独立可测、可独立回滚。

## 3. 工作流详解

### W-A 安全加固

#### W-A1 引擎回环守卫 middleware（本轮，S1/S2 根修）

**威胁模型**（对标 Jupyter #21 / VS Code #22）：
- T1 远端网页跨源读取 secrets / 调用写接口（CORS `*` 放大）；
- T2 DNS rebinding（attacker.com 解析到 127.0.0.1，Host 为攻击者域名）；
- 非目标：本地恶意进程（其本可直读 `.inkos/secrets.json`，防线在文件权限，服务侧无增量手段）。

**规则**（deny-first，仅拦浏览器形态请求）：

```
1. Origin 头存在：
   解析 Origin（scheme://host[:port]），
   放行 ⇔ scheme ∈ {http, https, tauri, tauri-webview...} 且 host 为回环主机
         （localhost / 127.0.0.1 / [::1] / [::]，端口不限制）
         或 scheme 非浏览器 schemes（如 tauri://localhost 的 host=localhost 天然命中回环）
         或 命中 env 追加名单 INKOS_ENGINE_ALLOWED_ORIGINS（逗号分隔，精确匹配）
   否则 → 403 {"error":"origin not allowed"}
2. Host 头存在：剥端口后必须是回环主机（或 env 名单主机）→ 否则 403（防 T2）
3. 两头皆缺（curl/健康探测/duel oneshot）→ 放行
```

**关键设计依据**：
- 端口不限的回环主机判定：Vite dev（4567 代理 Origin: localhost:4567）与 `pick_free_port` 动态端口均天然放行；远端 Origin 恒被拒。
- Host 校验剥端口：桌壳健康探测 `http://127.0.0.1:{port}` 的 Host 为 `127.0.0.1:{port}`，剥端口后放行。
- 缺头放行：保证 duel 测试（tower oneshot 无 Host/Origin）与 curl 零改动——**这是兼容性的关键**。
- 中间件挂载点：`inkos-engine-server` bin 的最外层（包 CORS 层之外），`router_books` 本身不动 → duel/单测默认不经过守卫，契约面零扰动；守卫行为用独立单测锁定。
- env：`INKOS_ENGINE_LOOPBACK_GUARD`（默认 on，`0`/`false` 关）；`INKOS_ENGINE_ALLOWED_ORIGINS`（追加精确 Origin 白名单，支持未来嵌入自定义 webview origin）。

**测试矩阵**：
| 用例 | 期望 |
|------|------|
| Origin: http://evil.com | 403 |
| Origin: http://localhost:5173（任意回环端口） | 放行 |
| Origin: http://127.0.0.1:7788 | 放行 |
| Origin: null（file:// 沙箱页） | 403（不冒险） |
| Origin: tauri://localhost | 放行（host 回环） |
| Origin + INKOS_ENGINE_ALLOWED_ORIGINS 命中 | 放行 |
| 无 Origin 无 Host（duel/curl 形态） | 放行 |
| Host: attacker.com:7788（rebinding） | 403 |
| Host: localhost:7788 / 127.0.0.1:7788 / [::1]:7788 | 放行 |
| 守卫 off（env） | 全放行 |
| 守卫拦下时 CORS 头不泄漏 | 响应无 access-control-* |

### W-B 性能与 0GC

#### W-B1 SSE/静态面分配复核（本轮，S7 修正版）

**实施期复核结论（2026-08-25，代码级验证）**：
- 原案「SsePayload String → Arc<str>」**取消**：axum `Sse` 的 `Event::event/data` 持有 `Cow<'static, str>`，Arc 化仅省去 broadcast channel 的逐订阅者克隆，但 yield 处仍须物化 String（`Cow` 所有权要求）——**每帧 memcpy 次数不变（每订阅者 1 次），净分配数为零收益**，与 02 号 roadmap 中"serde 栈缓冲回退"同属 API 边界决定的伪优化。登记结论防止后人重复尝试。
- 替代落地（真实收益）：静态面 SPA 回退的 `index.html` 缓存 `Vec<u8> → Bytes`——原实现每次回退请求整页 memcpy（index 典型 2-5 KB × 每次导航/刷新），`Bytes` 克隆为引用计数递增；读取时 `Vec → Bytes` 转移所有权零拷贝。
- 同时登记：SSE 帧序列化的每订阅者一次拷贝是 axum `Event` API 的固有代价，事件频率低（写周期级）不构成热点，**后续亦不值得绕过 axum 自造帧序列化**。

#### W-B2 引擎优雅停机（已落地，172 号；173 号修正超时语义）

bin 接 SIGTERM/ctrl_c → 广播 `engine:shutdown` 事件 → flush 窗口 → 关闭全部 SSE 流（`BroadcastHub` 增 watch 关闭通道，流内先排空管道残余事件再 EOF）→ axum graceful drain（排空段 5s 看门狗兜底）。原 kill_tree SIGTERM 整组杀兜底不变，本项消除"无限 SSE 流令 drain 永不完成"的结构性缺口。
**173 号修正**：172 号版把 `timeout(5s)` 包在 serve 整体上——引擎启动 5 秒后即被 timeout 砍掉自退（生产级回归；5s 内结束的冒烟/静态面 duel 从未触及）。改为 `hub.shutdown()` 后武装 5s drain 看门狗（drain 正常完成则随进程消亡），整体 serve 不再套超时。`INKOS_DUEL=1` 真跑 duel 8/8 暴露并锁定修复。

## 4. 风险与回滚

| 风险 | 概率 | 缓解 | 回滚 |
|------|------|------|------|
| 守卫误伤未知客户端（发送非回环 Origin 的合法工具） | 低 | 缺头放行 + 回环主机端口不限已覆盖全部已知客户端；env 追加名单兜底 | `INKOS_ENGINE_LOOPBACK_GUARD=0`（运行时）或 revert（代码级） |
| Host 校验影响 IPv6 环境探测 | 低 | `[::1]`/`[::]` 剥端口判定纳入测试矩阵 | 同上 |
| SSE Arc 化引起 borrow/生命周期编译问题 | 低 | 纯内部结构，yield 处显式转 `&str` | revert 单文件 |
| Node 侧守卫破坏 studio 自测（vitest 直连 server） | 低 | vitest 用 supertest/fetch 不带 Origin；回环 Host 放行 | 同款 env 开关 |
| 静态面 DENY 头影响某嵌入场景 | 极低 | webview 导航非 frame；现状无人嵌入 | 删一行 |
